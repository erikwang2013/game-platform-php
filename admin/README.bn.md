## পরিবেশের প্রয়োজনীয়তা

- PHP >= 8.3
- Composer 2.x
- MySQL >= 8.0
- Flutter >= 3.41 (শুধুমাত্র ফ্রন্টএন্ড ডেভেলপমেন্টের জন্য)
- Elasticsearch >= 7.x (ঐচ্ছিক, সার্চ ফিচারের জন্য)

## দ্রুত শুরু

### 1. ডিপেন্ডেন্সি ইনস্টল করুন

```bash
composer install
```

### 2. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন

এনভায়রনমেন্ট ভেরিয়েবল কপি ও সম্পাদনা করুন (ঐচ্ছিক, কনফিগার না করলে `config/*.php`-এর ডিফল্ট মান ব্যবহৃত হয়):

```bash
cp .env.example .env
```

মূল কনফিগারেশন আইটেম:

| এনভায়রনমেন্ট ভেরিয়েবল | বিবরণ | ডিফল্ট মান |
|---------|------|--------|
| `JWT_SECRET` | JWT সিগনেচার কী | `open-admin-jwt-secret-change-in-production` |
| `HASHIDS_SALT` | Hashids সল্ট | `open-admin-hashids-salt-2026` |
| `ENCRYPTION_KEY` | API এনক্রিপশন কী | ৩২ বাইট ডিফল্ট মান |
| `SNOWFLAKE_DATACENTER_ID` | ডেটাসেন্টার ID (0-31) | `1` |
| `SNOWFLAKE_WORKER_ID` | ওয়ার্কার নোড ID (0-31) | `1` |
| `SCOUT_HOSTS` | ES ঠিকানা | `http://localhost:9200` |

**প্রোডাকশনে অবশ্যই সব কী এলোমেলো স্ট্রিংয়ে পরিবর্তন করুন।**

### 3. ডেটাবেস ইনিশিয়ালাইজ করুন

`install/`-এর SQL ফাইলগুলো ক্রমানুসারে চালান:

```bash
mysql -u root -p < install/install.sql
```

### 4. সার্ভিস চালু করুন

```bash
php start.php start
```

ডিফল্টে `http://0.0.0.0:8787`-এ লিসেন করে।

### 5. ফ্রন্টএন্ড চালু করুন (ঐচ্ছিক)

**Flutter প্রশাসনিক প্যানেল (ওয়েব):**

```bash
cd apps/flutter
flutter pub get
flutter run -d chrome    # ওয়েব ভার্সন (PC প্রশাসনিক প্যানেল স্টাইল)
```

**HarmonyOS ক্লায়েন্ট (মোবাইল):**

DevEco Studio দিয়ে `apps/harmonyos/` ডিরেক্টরি খুলুন, রিয়েল ডিভাইস বা সিমুলেটর সংযুক্ত করে চালান।

### 6. Docker Compose ওয়ান-ক্লিক ডিপ্লয়মেন্ট (প্রোডাকশনে সুপারিশকৃত)

প্রজেক্টে সম্পূর্ণ Docker অর্কেস্ট্রেশন সমাধান রয়েছে, ৫টি সার্ভিস সহ: Nginx, PHP (webman app), MySQL, Redis, Elasticsearch।

```bash
# 1. Docker এনভায়রনমেন্ট ভেরিয়েবল কনফিগার
cp .env.docker .env

# 2. সব সার্ভিস চালু করুন
docker-compose up -d

# 3. ডেটাবেস ইনিশিয়ালাইজ (app কন্টেইনারে প্রবেশ করে চালান)
docker-compose exec app mysql -h mysql -u root -p < install/install.sql

# 4. প্রবেশ করুন
# http://localhost:8787  (webman)
# http://localhost:8080  (Nginx রিভার্স প্রক্সি)
```

- `Dockerfile`: PHP 8.3 + OPcache + Composer, `php:8.3-cli` ভিত্তিক
- `docker-compose.yml`: ৫টি সার্ভিস অর্কেস্ট্রেশন, নেটওয়ার্ক আইসোলেশন, ডেটা ভলিউম পারসিস্টেন্স
- `.env.docker`: Docker এনভায়রনমেন্ট বিশেষ এনভায়রনমেন্ট ভেরিয়েবল

## ডেটাবেস স্ট্যান্ডার্ড

- **টেবিল প্রিফিক্স**: `game_`
- **প্রাইমারি কী**: সব টেবিলের প্রাইমারি কী `id BIGINT UNSIGNED NOT NULL`, **AUTO_INCREMENT নিষিদ্ধ**
- **ID জেনারেশন**: প্রাইমারি কী ID অ্যাপ্লিকেশন লেয়ারের `SnowflakeService::generate()` দিয়ে তৈরি, ডিস্ট্রিবিউটেড ইউনিক
- **বাধ্যতামূলক ফিল্ড**: প্রতিটি টেবিলে অবশ্যই `id`, `created_at`, `updated_at` থাকবে
- **সফট ডিলিট**: সফট ডিলিটের প্রয়োজনীয় টেবিলে `deleted_at DATETIME DEFAULT NULL` যোগ করুন
- **সংবেদনশীল ফিল্ড**: ফোন নম্বর, ইমেইল, আইডি কার্ড নম্বর ইত্যাদি `encryptable` প্লাগইন দিয়ে স্বয়ংক্রিয় এনক্রিপশন/ডিক্রিপশন, ডেটাবেস ফিল্ড `VARCHAR(500)`-এ সাইফারটেক্সট স্টোর করে

### ID হ্যান্ডলিং

- **রিকোয়েস্ট/রেসপন্সে ID**: hashids দিয়ে স্ট্রিংয়ে এনক্রিপ্ট করা, প্রকৃত ডেটাবেস ID প্রকাশ হয় না
- **ইন্টারফেস পাথ**: `GET /admin/user/{hashid}` — পাথে `{id}` হল hashid স্ট্রিং
- **ডেটাবেস স্টোরেজ**: BIGINT আসল মান, snowflake দিয়ে তৈরি

### API ভার্সন

API ভার্সন রিকোয়েস্ট হেডার দিয়ে নিয়ন্ত্রিত, **URL-এ প্রকাশ পায় না**:

```http
API-Version: v1
```

- ভার্সন হেডার না থাকলে ডিফল্ট `v1` ব্যবহৃত হয়
- অসমর্থিত ভার্সনে `400 Bad Request` ফেরত আসে
- নতুন ভার্সন যোগ করতে শুধু `app/api/{version}/controller/` ডিরেক্টরি তৈরি করুন এবং মিডলওয়্যারে নতুন ভার্সন রেজিস্টার করুন

### রেট লিমিট

Redis স্লাইডিং উইন্ডো অ্যালগরিদম ভিত্তিক, ডিফল্ট ৬০ বার/মিনিট/IP/রুট। সংবেদনশীল ইন্টারফেস আরও কঠোর:
- লগইন: ১০ বার/মিনিট
- রেজিস্ট্রেশন: ৫ বার/মিনিট

রেসপন্স হেডারে `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` থাকে। সীমা অতিক্রম করলে 429 ফেরত আসে এবং `Retry-After` সংযুক্ত থাকে।

### মিডলওয়্যার আর্কিটেকচার

গ্লোবাল মিডলওয়্যার সব রিকোয়েস্টে ক্রমানুসারে প্রযোজ্য:

```
Cors（跨域预处理 + 响应头）
  → SecurityFilter（HTTP方法限制/请求体大小/Content-Type校验/XSS/SQL注入/路径遍历/命令注入/CSRF 攻击拦截）
  → RateLimit（Redis 滑动窗口限流 + 账号锁定：5次登录失败锁定15分钟）
  → ApiVersion（API 版本校验，/api 路由组）
  → AdminAuth（JWT 认证 + 黑名单，/admin 路由组）
  → AdminPermission（RBAC 鉴权，/admin 路由组）
  → OperationLog（POST/PUT/DELETE 自动记录，含来源端检测，/admin 路由组）
```

`/health` এবং `/api/docs` হল পাবলিক এন্ডপয়েন্ট, শুধুমাত্র `Cors → SecurityFilter → RateLimit`-এর মধ্য দিয়ে যায়।

নিরাপত্তা বৃদ্ধি:
- **অ্যাকাউন্ট লক**: টানা ৫ বার লগইন ব্যর্থ হলে অ্যাকাউন্ট স্বয়ংক্রিয়ভাবে ১৫ মিনিট লক হয়, এই সময়ে লগইনে 429 ফেরত আসে
- **কনকারেন্ট সেশন সীমা**: একই ইউজারের সর্বোচ্চ ৩টি ভ্যালিড Token, এর বেশি হলে সবচেয়ে পুরনো Token স্বয়ংক্রিয়ভাবে ব্ল্যাকলিস্টে যায়
- **security.txt**: `GET /.well-known/security.txt` RFC 9116 স্ট্যান্ডার্ড নিরাপত্তা যোগাযোগ তথ্য দেয়
- **Nginx নিরাপত্তা কনফিগারেশন**: সম্পূর্ণ রিভার্স প্রক্সি নিরাপত্তা হার্ডেনিং উদাহরণের জন্য `docs/nginx-security.conf` দেখুন

### অথেনটিকেশন

লগইন ও রেজিস্ট্রেশনের আগে **ক্লিক ক্যাপচা** ভেরিফিকেশন পাস করতে হবে:

1. ক্লায়েন্ট `POST /api/captcha/generate` রিকোয়েস্ট করে ক্যাপচা ইমেজ (base64 PNG) ও টার্গেট শব্দের তালিকা পায়
2. ব্যবহারকারী ক্রমানুসারে ছবিতে সংশ্লিষ্ট শব্দের অবস্থানে ক্লিক করে, ক্লিক কোঅর্ডিনেট `[{x, y}, ...]` সংগ্রহ হয়
3. লগইনের সময় একসাথে `captcha_key` ও `clicks` জমা দিতে হয়, সার্ভার প্রথমে ক্যাপচা তারপর ক্রেডেনশিয়াল ভেরিফাই করে

```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "******",
  "captcha_key": "abc123...",
  "clicks": [{"x": 120, "y": 85}, {"x": 210, "y": 140}, {"x": 95, "y": 170}]
}
```

প্রশাসনিক প্যানেলের পরবর্তী ইন্টারফেসগুলিতে JWT অথেনটিকেশন প্রয়োজন:

```http
Authorization: Bearer <token>
```

লগইন সফল হলে access_token ফেরত আসে, মেয়াদ ২ ঘণ্টা; এছাড়াও refresh_token ফেরত আসে, মেয়াদ ১৪ দিন।

লগআউটের সময় Token Redis ব্ল্যাকলিস্টে যায়, মেয়াদের মধ্যে পুনরায় ব্যবহার করা যায় না। POST /admin/profile/logout

### সংবেদনশীল অপারেশনের দ্বিতীয় নিশ্চিতকরণ

ইউজার, রোল, পারমিশন ডিলিটের মতো সংবেদনশীল অপারেশনে রিকোয়েস্ট বডিতে বর্তমান লগইন ইউজারের `password` পাঠিয়ে পরিচয় দ্বিতীয়বার নিশ্চিত করতে হবে:

```http
DELETE /admin/user/{id}
Content-Type: application/json
Authorization: Bearer <token>

{ "password": "******" }
```

- **পেজ**: লগইন, ড্যাশবোর্ড, ইউজার তালিকা/বিস্তারিত, ব্যক্তিগত সেন্টার
- **অথেনটিকেশন**: JWT Bearer + 401-এ স্বয়ংক্রিয় সিলেন্ট Token রিফ্রেশ, রিফ্রেশ ব্যর্থ হলে স্বয়ংক্রিয়ভাবে লগইন পেজে রিডাইরেক্ট
- **স্টোরেজ**: Token AppStorage দিয়ে ম্যানেজ করা হয়

## ডেভেলপমেন্ট গাইডলাইন

- গ্লোবাল ফাংশন/ক্লাস রেফারেন্সে আগে `\` দেওয়া হয় না, সব জায়গায় `use` ইমপোর্ট
- সব PHP ফাইলের শীর্ষে কপিরাইট ডিক্লারেশন থাকতে হবে
- সব কনফিগারেশন ফাইলে চীনা কমেন্ট বিবরণ থাকতে হবে
- ডেটাবেস প্রাইমারি কী অবশ্যই অ্যাপ্লিকেশন লেয়ারের snowflake দিয়ে তৈরি হতে হবে, অটোইনক্রিমেন্ট নিষিদ্ধ
- API লেয়ারের সব প্যারামিটার ও রেসপন্সের ID অবশ্যই hashids দিয়ে এনক্রিপশন/ডিক্রিপশন করতে হবে
- AdminPermission মিডলওয়্যার Redis ক্যাশ ব্যবহার করে ইউজার পারমিশন (TTL=60s), N+1 কোয়েরি বটলনেক দূর করে

## ডিপ্লয়মেন্ট

### Docker Compose (সুপারিশকৃত)

প্রজেক্ট রুটে `docker-compose.yml` রয়েছে, ৫টি সার্ভিস অর্কেস্ট্রেট করে:

| সার্ভিস | ইমেজ | পোর্ট |
|------|------|------|
| `nginx` | nginx:alpine | 80, 443 |
| `app` | লোকাল `Dockerfile` দিয়ে বিল্ড | 8787 |
| `mysql` | mysql:8.0 | 3306 |
| `redis` | redis:7-alpine | 6379 |
| `elasticsearch` | elasticsearch:8.x | 9200 |

PHP ইমেজ `Dockerfile` দিয়ে বিল্ড হয়, বেস ইমেজ `php:8.3-cli`, OPcache সক্ষম।

```bash
cp .env.docker .env
docker-compose up -d
```

### CI/CD

GitHub Actions কন্টিনিউয়াস ইন্টিগ্রেশন পাইপলাইন: `.github/workflows/ci.yml`

- PHP সিনট্যাক্স চেক (`php -l`)
- PHPUnit ইউনিট টেস্ট
- Flutter স্ট্যাটিক অ্যানালাইসিস (`flutter analyze`)

### ডেটাবেস ব্যাকআপ

`database/backup/` ডিরেক্টরি:

- `backup.sh` — mysqldump + gzip ব্যাকআপ, ৩০ দিন আগের পুরনো ব্যাকআপ স্বয়ংক্রিয় পরিষ্কার
- `restore.sh` — ইন্টারঅ্যাকটিভ রিস্টোর, উপলব্ধ ব্যাকআপ তালিকা দেখিয়ে নির্বাচন করায়

### Nginx নিরাপত্তা কনফিগারেশন

প্রোডাকশন ডিপ্লয়মেন্টে রিভার্স প্রক্সি নিরাপত্তা হার্ডেনিংয়ের জন্য `docs/nginx-security.conf` কনফিগারেশন অনুসরণ করুন।
