الواجهة الأمامية للوحة الإدارة المبنية على Flutter 3.x، بتخطيط إدارة كلاسيكي للحاسوب (شريط جانبي + شريط علوي + منطقة محتوى). تغطي جميع صفحات الإدارة اللازمة لتشغيل منصة الألعاب: لوحة المعلومات، المستخدمون، الأدوار والصلاحيات، الألعاب، المدفوعات، السحب، VIP، الإنجازات، الإعلانات، CDN، إدارة المخاطر، التحقق من الهوية، سجلات العمليات وغيرها.

## قائمة الوظائف

| الوحدة | الوصف |
|------|------|
| لوحة المعلومات | نظرة عامة على بيانات التشغيل |
| التقارير | ملخص التقارير/اليومي/تصدير CSV |

| تسجيل الدخول | دخول المدير (مع 2FA) |
| إدارة المستخدمين | البحث عن المستخدمين وإدارتهم |
| مستخدمو المنصة | تفاصيل المستخدم والحالة وعمليات الرصيد |
| الأدوار والصلاحيات | تخصيص الأدوار والصلاحيات |
| إعدادات النظام | ضبط معلمات المنصة |
| إدارة الألعاب | قائمة الألعاب والنشر/الإيقاف والتصنيفات |
| إدارة المدفوعات | طلبات الإيداع ووسائل الدفع وسجلات الاستدعاء |
| إدارة السحب | مراجعة السحب والدفع |
| إدارة VIP | ضبط مستويات ومزايا VIP |
| إدارة الإنجازات | تعريفات الإنجازات وعرض التقدم |
| إدارة الإعلانات | نشر الإعلانات وإيقافها |
| إدارة CDN | ضبط موفري CDN والنطاقات |
| إدارة المخاطر | قواعد المخاطر وسجلات الحظر |
| التحقق من الهوية | مراجعة بيانات الاسم الحقيقي |
| سجل العمليات | سجل تدقيق إجراءات المدير |
| الملف الشخصي | ملف المدير وإعدادات الأمان |

## المتطلبات

- Flutter SDK 3.x

## التثبيت والتشغيل

```bash
cd admin/apps/flutter

# تثبيت الاعتماديات
flutter pub get

# التشغيل في وضع التطوير (Chrome)
flutter run -d chrome

# تحديد عنوان الخادم الخلفي (الافتراضي http://localhost:8787)
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8787

# بناء نسخة الإنتاج للويب (الإخراج في build/web/)
flutter build web
```

## الاستخدام

1. شغّل أولاً خدمة الخادم الخلفي للوحة الإدارة: `cd admin && php start.php start -d` (المنفذ الافتراضي 8787)
2. سجّل الدخول بحساب المدير الذي أنشأه معالج التثبيت (يدعم 2FA)
3. واجهة المستخدم موجودة في `apps/flutter/platform/` وتستخدم نفس خدمة الخادم الخلفي (المنفذ الافتراضي 8788)
