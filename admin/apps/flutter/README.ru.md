Веб-фронтенд админ-панели на Flutter 3.x с классическим PC-макетом (сайдбар + верхняя панель + область контента), покрывающий все страницы управления игровой платформой: дашборд, пользователи, роли и права, игры, платежи, выводы, VIP, достижения, объявления, CDN, риск-контроль, верификация личности, журнал операций и др.

## Список функций

| Модуль | Описание |
|------|------|
| Дашборд | Обзор операционных данных платформы |
| Отчёты | Сводка отчётов/ежедневные/CSV-экспорт |

| Вход | Вход администратора (включая 2FA) |
| Управление пользователями | Поиск и управление пользователями |
| Пользователи платформы | Детали пользователя, статус и операции с балансом |
| Роли и права | Назначение ролей и прав |
| Системные настройки | Конфигурация параметров платформы |
| Управление играми | Список игр, публикация/остановка и категории |
| Управление платежами | Депозитные ордера, способы оплаты и логи колбэков |
| Управление выводами | Проверка и выплата выводов |
| Управление VIP | Настройка уровней и привилегий VIP |
| Управление достижениями | Определения достижений и просмотр прогресса |
| Управление объявлениями | Публикация и снятие объявлений |
| Управление CDN | Конфигурация провайдеров CDN и доменов |
| Риск-контроль | Правила риска и записи блокировок |
| Верификация личности | Проверка данных реального имени |
| Журнал операций | Аудит действий администраторов |
| Личный кабинет | Профиль и настройки безопасности |

## Требования

- Flutter SDK 3.x

## Установка и запуск

```bash
cd admin/apps/flutter

# Установка зависимостей
flutter pub get

# Запуск в режиме разработки (Chrome)
flutter run -d chrome

# Указать адрес бэкенда (по умолчанию http://localhost:8787)
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8787

# Сборка production-версии для Web (вывод в build/web/)
flutter build web
```

## Использование

1. Сначала запустите бэкенд админ-панели: `cd admin && php start.php start -d` (порт по умолчанию 8787)
2. Войдите с аккаунтом администратора, созданным мастером установки (поддерживается 2FA)
3. Пользовательский фронтенд находится в `apps/flutter/platform/` и использует тот же бэкенд (порт по умолчанию 8788)
