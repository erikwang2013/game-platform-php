C-সাইড ইউজার প্ল্যাটফর্ম API সার্ভিস — webman v2 (Workerman) ভিত্তিক একটি উচ্চক্ষমতাসম্পন্ন PHP ব্যাকএন্ড, যা ব্যবহারকারীদের গেম অ্যাগ্রিগেশন প্ল্যাটফর্মের সম্পূর্ণ সক্ষমতা প্রদান করে: রেজিস্ট্রেশন ও লগইন, ওয়ালেট, ডিপোজিট, উইথড্রয়াল, এক্সচেঞ্জ, গেম, লিডারবোর্ড, কুপন, সাপোর্ট টিকেট, VIP, অ্যাচিভমেন্ট, সামাজিক ফিচার ও নোটিশ।

## ফিচার তালিকা

| মডিউল | বিবরণ |
|------|------|
| ব্যবহারকারী | রেজিস্ট্রেশন/লগইন (ইউজারনেম+পাসওয়ার্ড + ৭টি প্ল্যাটফর্মের OAuth + 2FA TOTP), প্রোফাইল |
| ওয়ালেট | প্ল্যাটফর্ম কয়েন ওয়ালেট (অপটিমিস্টিক লক) + গেম কয়েন ওয়ালেট + লেনদেনের ইতিহাস |
| ডিপোজিট | ১৩টি পেমেন্ট গেটওয়ে (Stripe/PayPal/NowPayments/Coinbase ইত্যাদি) কলব্যাক স্বাক্ষর যাচাই ও স্বয়ংক্রিয় ক্রেডিট |
| উইথড্রয়াল | আবেদন → যাচাই → পরিশোধ, KYC ধাপভিত্তিক সীমা |
| এক্সচেঞ্জ | প্ল্যাটফর্ম কয়েন ⇄ গেম কয়েন রিয়েল-টাইম কোটেশন, VIP ডিসকাউন্ট ও রেট বোনাস |
| গেম | গেম তালিকা/ক্যাটাগরি/সার্চ, প্লে রেকর্ড, Provider সেটেলমেন্ট কলব্যাক |
| লিডারবোর্ড | দৈনিক/সাপ্তাহিক/মাসিক/সর্বকাল + WebSocket রিয়েল-টাইম পুশ |
| কুপন | নির্দিষ্ট পরিমাণ + শতাংশ ডিসকাউন্ট, সময় ও সংখ্যা সীমিত |
| টিকেট | ব্যবহারকারীর সাপোর্ট টিকেট তৈরি/উত্তর |
| VIP | ৫ স্তরের রয়্যালটি, অভিজ্ঞতা সঞ্চয়, এক্সচেঞ্জ ডিসকাউন্ট |
| অ্যাচিভমেন্ট | ১২টি বিল্ট-ইন অ্যাচিভমেন্ট, ইভেন্ট-চালিত ডিটেকশন |
| সামাজিক | বন্ধু সিস্টেম + WebSocket রিয়েল-টাইম মেসেজিং |
| নোটিশ | অ্যাপ-মধ্যস্থ নোটিশ + নোটিফিকেশন/ইমেইল |

## টেক স্ট্যাক

- PHP 8.3+ / webman v2 (workerman/webman)
- MySQL 8.0+ (টেবিল প্রিফিক্স `game_`, BIGINT নন-অটোইনক্রিমেন্ট প্রাইমারি কী)
- Redis (সেশন / ক্যাশ / রেট লিমিটিং)
- ClickHouse (OLAP অ্যানালিটিক্স / প্রোবাবিলিটি ক্যালকুলেশন)
- Elasticsearch (ফুল-টেক্সট সার্চ)
- JWT অথেনটিকেশন + HMAC-SHA256 Provider স্বাক্ষর

## প্রজেক্ট স্ট্রাকচার

```
service/
├── app/
│   ├── api/v1/controller/  # C-সাইড API কন্ট্রোলার (৩৫টি)
│   ├── middleware/         # মিডলওয়্যার (Cors/SecurityFilter/RateLimit/ApiVersion/UserAuth/ProviderAuth)
│   ├── model/              # ডেটা মডেল
│   ├── service/            # বিজনেস সার্ভিস (VIP/লিডারবোর্ড/রিস্ক/নোটিফিকেশন ইত্যাদি)
│   ├── event/              # ইভেন্ট বাস (EventBus Redis Pub/Sub)
│   ├── provider/           # গেম Provider লেয়ার
│   └── payment/            # পেমেন্ট গেটওয়ে
├── common/                 # শেয়ার্ড সার্ভিস ডিরেক্টরি (erik/platform-common প্যাকেজে বাস্তবায়িত)
├── config/                 # কনফিগারেশন ফাইল
├── public/                 # ওয়েব এন্ট্রি
├── tests/                  # PHPUnit টেস্ট
├── start.php               # স্টার্টআপ এন্ট্রি
└── composer.json
```

## ওয়ান-ক্লিক ইনস্টলেশন

প্রজেক্ট রুটের ওয়ান-ক্লিক ইনস্টলেশন উইজার্ড ব্যবহার করুন (প্রজেক্ট রুট থেকে চালান):

```bash
# 1. ইনস্টলেশন উইজার্ড চালু করুন
php -S 0.0.0.0:8888 -t install/

# 2. ব্রাউজারে http://localhost:8888 খুলুন
#    উইজার্ড অনুসরণ করুন: এনভায়রনমেন্ট চেক → ডেটাবেস কনফিগ → অ্যাডমিন অ্যাকাউন্ট → অটো-ইনস্টল
```

অথবা Docker Compose দিয়ে সবকিছু চালু করুন (প্রজেক্ট রুট):

```bash
docker compose up -d
```

## ম্যানুয়াল ইনস্টলেশন

```bash
# 1. ডিপেন্ডেন্সি ইনস্টল করুন
cd service && composer install

# 2. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন
cp .env.example .env
# .env এডিট করুন: ডেটাবেস সংযোগ, JWT কী ইত্যাদি

# 3. সার্ভিস চালু করুন (ডিফল্ট পোর্ট 8788)
php start.php start        # ফোরগ্রাউন্ড
php start.php start -d     # ব্যাকগ্রাউন্ড (ডেমন)
```

## ব্যবহার

- API ডক: `docs/API.md` (সম্পূর্ণ API রেফারেন্স)
- অনলাইন ডক: http://localhost:8788/apidoc/ (hg/apidoc ইন্টারঅ্যাকটিভ ডক)
- হেলথ চেক: `GET http://localhost:8788/health`
- C-সাইড ফ্রন্টএন্ড: `apps/flutter/platform/` (Flutter Web ইউজার প্ল্যাটফর্ম)
- অ্যাডমিন ব্যাকএন্ড: `admin/` (অ্যাডমিন ব্যাকএন্ড ও `admin/apps/flutter/` ফ্রন্টএন্ড)
