API-сервис пользовательской платформы (C-сторона) — высокопроизводительный PHP-бэкенд на базе webman v2 (Workerman), предоставляющий пользователям полный функционал игровой агрегационной платформы: регистрация и вход, кошелёк, пополнение, вывод, обмен, игры, рейтинги, купоны, тикеты поддержки, VIP, достижения, соцфункции и объявления.

## Возможности

| Модуль | Описание |
|------|------|
| Пользователи | Регистрация/вход (логин+пароль + OAuth 7 платформ + 2FA TOTP), профиль |
| Кошелёк | Кошелёк платформенных монет (оптимистичная блокировка) + кошелёк игровых монет + история операций |
| Пополнение | 13 платёжных шлюзов (Stripe/PayPal/NowPayments/Coinbase и др.), проверка подписи колбэков, автозачисление |
| Вывод | Заявка → проверка → выплата, ступенчатые лимиты KYC |
| Обмен | Реальные котировки платформенных ⇄ игровых монет, VIP-скидки и бонусы к курсу |
| Игры | Список/категории/поиск игр, история, колбэки расчёта Provider |
| Рейтинги | День/неделя/месяц/всё время + WebSocket-пуши в реальном времени |
| Купоны | Фиксированная сумма + процентная скидка, ограничения по времени и количеству |
| Тикеты | Создание/ответы на тикеты поддержки |
| VIP | 5 уровней лояльности, накопление опыта, скидки на обмен |
| Достижения | 12 встроенных достижений, обнаружение по событиям |
| Соцфункции | Система друзей + WebSocket-личные сообщения в реальном времени |
| Объявления | Внутренние объявления + уведомления/email |

## Технологии

- PHP 8.3+ / webman v2 (workerman/webman)
- MySQL 8.0+ (префикс таблиц `game_`, BIGINT-ключи без автоинкремента)
- Redis (сессии / кэш / ограничение частоты)
- ClickHouse (OLAP-аналитика / расчёт вероятностей)
- Elasticsearch (полнотекстовый поиск)
- JWT-аутентификация + HMAC-SHA256 подпись Provider

## Установка в один клик

Рекомендуется мастер установки в корне проекта (выполнять из корня проекта):

```bash
# 1. Запустите мастер установки
php -S 0.0.0.0:8888 -t install/

# 2. Откройте http://localhost:8888 в браузере
#    Следуйте мастеру: проверка окружения → настройка БД → создание администратора → автоустановка
```

Или запустите всё через Docker Compose (корень проекта):

```bash
docker compose up -d
```

## Ручная установка

```bash
# 1. Установите зависимости
cd service && composer install

# 2. Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env: подключение к БД, JWT-ключи и т.д.

# 3. Запустите сервис (порт по умолчанию 8788)
php start.php start        # на переднем плане
php start.php start -d     # в фоне (демон)
```

## Использование

- Справочник API: `docs/API.md` (полный справочник)
- Онлайн-документация: http://localhost:8788/apidoc/ (интерактивная документация hg/apidoc)
- Проверка здоровья: `GET http://localhost:8788/health`
- Фронтенд C-стороны: `apps/flutter/platform/` (пользовательская платформа Flutter Web)
- Админка: `admin/` (бэкенд админки и фронтенд `admin/apps/flutter/`)
