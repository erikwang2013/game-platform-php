# game_platform

## प्रोजेक्ट मास्कट

<img src="../../../docs/mascot.svg" width="120" alt="Dicey"/>

**डाइसी (Dicey)** — प्लेटफ़ॉर्म मास्कट। पासा गेम और संभावना-आधारित गेमप्ले को दर्शाता है, सिक्का प्लेटफ़ॉर्म अर्थव्यवस्था और मल्टी-पेमेंट गेटवे को, और बैंगनी रंग एडमिन ब्रांडिंग को दर्शाता है। SVG फ़ाइल: `docs/mascot.svg`, दस्तावेज़ों, लोगो और सामान के लिए असीमित स्केलेबल।

## आरंभ करना

यह प्रोजेक्ट एक Flutter एप्लिकेशन के लिए प्रारंभिक बिंदु है।

यदि यह आपका पहला Flutter प्रोजेक्ट है, तो आरंभ करने के लिए कुछ संसाधन:

- [Flutter सीखें](https://docs.flutter.dev/get-started/learn-flutter)
- [अपना पहला Flutter ऐप लिखें](https://docs.flutter.dev/get-started/codelab)
- [Flutter सीखने के संसाधन](https://docs.flutter.dev/reference/learning-resources)

Flutter विकास आरंभ करने में सहायता के लिए, [ऑनलाइन दस्तावेज़](https://docs.flutter.dev/) देखें, जिसमें ट्यूटोरियल, नमूने, मोबाइल विकास मार्गदर्शन और संपूर्ण API संदर्भ उपलब्ध हैं।
