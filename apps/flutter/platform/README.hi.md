C-साइड उपयोगकर्ता प्लेटफ़ॉर्म का वेब फ्रंटएंड, Flutter 3.x पर आधारित, उपयोगकर्ताओं को गेम एग्रीगेशन प्लेटफ़ॉर्म का संपूर्ण अनुभव प्रदान करता है: पंजीकरण और लॉगिन, गेम लॉबी, वॉलेट, जमा, निकासी, विनिमय, लीडरबोर्ड, कूपन, सूचनाएँ, चैट, मित्र और सपोर्ट टिकट।

## सुविधा सूची

| मॉड्यूल | विवरण |
|------|------|
| लॉगिन/पंजीकरण | यूज़रनेम+पासवर्ड / OAuth / 2FA |
| गेम लॉबी | गेम सूची/श्रेणियाँ/खोज |
| वॉलेट | प्लेटफ़ॉर्म/गेम कॉइन शेष और लेन-देन |
| जमा | भुगतान विधि चुनें, गेटवे भुगतान पर रीडायरेक्ट |
| निकासी | निकासी के लिए आवेदन, स्थिति ट्रैकिंग |
| विनिमय | प्लेटफ़ॉर्म कॉइन ⇄ गेम कॉइन रीयल-टाइम विनिमय |
| लीडरबोर्ड | दैनिक/साप्ताहिक/मासिक/सर्वकालिक |
| कूपन | प्राप्त करें और उपयोग करें |
| सूचनाएँ | ऐप में संदेश (जमा/निकासी/कूपन आदि) |
| चैट | WebSocket रीयल-टाइम संदेश |
| मित्र | मित्र प्रणाली |
| टिकट | सपोर्ट टिकट बनाना और उत्तर |
| प्रोफ़ाइल | प्रोफ़ाइल संपादन/सुरक्षा सेटिंग्स |

## आवश्यकताएँ

- Flutter SDK 3.x

## स्थापना और चलाना

```bash
cd apps/flutter/platform

# निर्भरताएँ स्थापित करें
flutter pub get

# विकास में चलाएँ (Chrome)
flutter run -d chrome

# बैकएंड पता निर्दिष्ट करें (डिफ़ॉल्ट http://localhost:8788)
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8788

# वेब प्रोडक्शन बिल्ड (आउटपुट build/web/ में)
flutter build web
```

## उपयोग

1. पहले बैकएंड सेवा शुरू करें: `cd service && php start.php start -d` (डिफ़ॉल्ट पोर्ट 8788)
2. खाता पंजीकृत करें और लॉगिन करें (यूज़रनेम+पासवर्ड, OAuth और 2FA समर्थित)
3. जमा के बाद प्लेटफ़ॉर्म कॉइन से खेलें और गेम कॉइन में बदलें; गेम कॉइन को वापस वॉलेट में बदलकर निकासी की जा सकती है
4. एडमिन बैकएंड `admin/` निर्देशिका में है (Flutter Web फ्रंटएंड `admin/apps/flutter/` सहित)
