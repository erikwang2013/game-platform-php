Веб-фронтенд пользовательской платформы (C-сторона) на базе Flutter 3.x, предоставляющий пользователям полный опыт игровой агрегационной платформы: регистрация и вход, игровой холл, кошелёк, пополнение, вывод, обмен, рейтинги, купоны, уведомления, чат, друзья и тикеты поддержки.

## Возможности

| Модуль | Описание |
|------|------|
| Вход/регистрация | Логин+пароль / OAuth / 2FA |
| Игровой холл | Список/категории/поиск игр |
| Кошелёк | Балансы и операции платформенных/игровых монет |
| Пополнение | Выбор способа оплаты, переход к оплате через шлюз |
| Вывод | Заявка на вывод, отслеживание статуса |
| Обмен | Реальный обмен платформенных ⇄ игровых монет |
| Рейтинги | День/неделя/месяц/всё время |
| Купоны | Получение и использование |
| Уведомления | Внутренние сообщения (пополнение/вывод/купоны и т.д.) |
| Чат | WebSocket-сообщения в реальном времени |
| Друзья | Система друзей |
| Тикеты | Создание и ответы на тикеты поддержки |
| Профиль | Редактирование профиля/настройки безопасности |

## Требования

- Flutter SDK 3.x

## Установка и запуск

```bash
cd apps/flutter/platform

# Установка зависимостей
flutter pub get

# Запуск в режиме разработки (Chrome)
flutter run -d chrome

# Указать адрес бэкенда (по умолчанию http://localhost:8788)
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8788

# Сборка web-версии для продакшена (вывод в build/web/)
flutter build web
```

## Использование

1. Сначала запустите бэкенд: `cd service && php start.php start -d` (порт по умолчанию 8788)
2. Зарегистрируйте аккаунт и войдите (поддерживаются логин+пароль, OAuth, 2FA)
3. После пополнения можно играть на платформенные монеты и обменивать их на игровые; игровые монеты можно вернуть в кошелёк и вывести
4. Админка — в каталоге `admin/` (включая веб-фронтенд `admin/apps/flutter/`)
