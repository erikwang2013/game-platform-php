C-সাইড ইউজার প্ল্যাটফর্মের ওয়েব ফ্রন্টএন্ড, Flutter 3.x ভিত্তিক, যা ব্যবহারকারীদের গেম অ্যাগ্রিগেশন প্ল্যাটফর্মের সম্পূর্ণ অভিজ্ঞতা দেয়: রেজিস্ট্রেশন ও লগইন, গেম লবি, ওয়ালেট, ডিপোজিট, উইথড্রয়াল, এক্সচেঞ্জ, লিডারবোর্ড, কুপন, নোটিফিকেশন, চ্যাট, বন্ধু এবং সাপোর্ট টিকেট।

## ফিচার তালিকা

| মডিউল | বিবরণ |
|------|------|
| লগইন/রেজিস্ট্রেশন | ইউজারনেম+পাসওয়ার্ড / OAuth / 2FA |
| গেম লবি | গেম তালিকা/ক্যাটাগরি/সার্চ |
| ওয়ালেট | প্ল্যাটফর্ম/গেম কয়েন ব্যালেন্স ও লেনদেন |
| ডিপোজিট | পেমেন্ট মাধ্যম বেছে নিয়ে গেটওয়ে পেমেন্টে যান |
| উইথড্রয়াল | উইথড্রয়াল আবেদন, রিভিউ অবস্থা ট্র্যাকিং |
| এক্সচেঞ্জ | প্ল্যাটফর্ম কয়েন ⇄ গেম কয়েন রিয়েল-টাইম এক্সচেঞ্জ |
| লিডারবোর্ড | দৈনিক/সাপ্তাহিক/মাসিক/সর্বকাল |
| কুপন | গ্রহণ ও ব্যবহার |
| নোটিফিকেশন | অ্যাপ-মধ্যস্থ বার্তা (ডিপোজিট/উইথড্রয়াল/কুপন ইত্যাদি) |
| চ্যাট | WebSocket রিয়েল-টাইম মেসেজিং |
| বন্ধু | বন্ধু সিস্টেম |
| টিকেট | সাপোর্ট টিকেট তৈরি ও উত্তর |
| প্রোফাইল | প্রোফাইল সম্পাদনা/নিরাপত্তা সেটিংস |

## প্রয়োজনীয়তা

- Flutter SDK 3.x

## ইনস্টল ও চালানো

```bash
cd apps/flutter/platform

# ডিপেন্ডেন্সি ইনস্টল
flutter pub get

# ডেভেলপমেন্টে চালান (Chrome)
flutter run -d chrome

# ব্যাকএন্ড ঠিকানা নির্ধারণ (ডিফল্ট http://localhost:8788)
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8788

# ওয়েব প্রোডাকশন বিল্ড (আউটপুট build/web/-এ)
flutter build web
```

## ব্যবহার

1. আগে ব্যাকএন্ড সার্ভিস চালু করুন: `cd service && php start.php start -d` (ডিফল্ট পোর্ট 8788)
2. অ্যাকাউন্ট রেজিস্টার করে লগইন করুন (ইউজারনেম+পাসওয়ার্ড, OAuth ও 2FA সমর্থিত)
3. ডিপোজিটের পর প্ল্যাটফর্ম কয়েনে খেলুন এবং গেম কয়েনে বিনিময় করুন; গেম কয়েন ফিরিয়ে ওয়ালেটে এনে উইথড্র করা যায়
4. অ্যাডমিন ব্যাকএন্ড `admin/` ডিরেক্টরিতে (Flutter Web ফ্রন্টএন্ড `admin/apps/flutter/` সহ)
