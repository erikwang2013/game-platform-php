## 2. C-छोर उपयोगकर्ता सुविधाएँ

### 2.1 उपयोगकर्ता यात्रा

```
पंजीकरण → लॉगिन → ईमेल/फ़ोन सत्यापन → गेम लॉबी ब्राउज़ → गेम विवरण में प्रवेश
                                           ↓
वॉलेट देखें ← गेम खेलें ← गेम कॉइन विनिमय (VIP छूट) ← प्लेटफ़ॉर्म कॉइन रिचार्ज
    ↓
  निकासी (VIP शुल्क में कटौती) → बैकएंड समीक्षा → जमा
    ↓
मित्र प्रणाली → निजी संदेश चैट → लीडरबोर्ड प्रतिस्पर्धा → उपलब्धि ट्रैकिंग
    ↓
टिकट समर्थन
```
