### 二、 核心规则拓展（“生态克制链”设计）

你的规则逻辑本质是**“定向消除”**。在传统三消（三个相同即消除）基础上，我们嵌入**“捕食/克制匹配”**。当玩家将**克制者**与**被克制者**凑成三个一排（或特定图形）时，触发高级消除。

以下是我为你拓展的**完整克制矩阵**（A 克制 B）：

| 克制者 (A) | 克制方式 | 被克制者 (B) | 拓展规则说明 |
| :--- | :--- | :--- | :--- |
| **鸡、鸭、鹅** | 啄食 / 捕食 | 花草、蔬果、昆虫（蚂蚁/瓢虫/毛毛虫） | 补充：它们**不吃**五谷（庄稼），因为谷子太硬，需要单独消除。 |
| **狗** | 撕咬 | 鸡、鸭、鹅、鸽子 | 狗不仅咬家禽，补充**狗也啃骨头（对应猪/牛/马的骨头）**，但游戏里取简化，克制所有中小型家禽。 |
| **猪** | 拱 / 糟蹋 | 树木、花草、蔬果、昆虫、**所有五谷庄稼** | 猪是破坏王，补充：猪**不拱**狗（因为狗会咬猪），形成克制闭环。 |
| **牛、马** | 啃食 / 踩踏 | 花草、**五谷庄稼**、果树苗 | 补充牛马作为食草大牲口，专门克制农作物，但不吃昆虫和肉类。 |
| **大象** | 绝对压制（踩/甩） | **除大象外所有元素（包括猪狗牛马）** | 大象是顶级战力。为了平衡，补充：大象**不能**消除“农具”（道具），且大象在棋盘上出现概率极低（稀有棋子）。 |
| **镰刀（道具）** | 收割 | 所有五谷庄稼、花草 | 一次性清除横排或竖排的所有植物系。 |
| **锄头（道具）** | 砸碎 | 树木、石头（障碍） | 专门清除厚血障碍物。 |

### 三、 玩法机制设计（如何操作“消消乐”）

在Three.js的3D场景中，我们采用**“点击交换+生态判定”**的融合模式：

1.  **基础操作**：玩家点击两个相邻的3D棋子进行位置互换。
2.  **判定逻辑（关键）**：
    - **同种消除**：互换后，若横竖形成 **≥3个相同棋子**，执行基础消除（例如三个苹果）。
    - **生态消除（特殊）**：互换后，若横竖形成 **“克制者 + 任意两个被克制者”**（如：鸡 + 虫 + 虫），**不要求三个都相同**，直接触发“捕食动画”，鸡吃掉虫子，额外加分，并且该格会生成一个**“粪便肥料”**（增益buff，下次消除得分翻倍）。
    - **大象特权**：大象与**任意两个不同棋子**排成一行，都会触发“欺负”效果，直接清空那三个格子，无视种族。
3.  **连锁反应（Combo）**：棋子消除后上方掉落填补。如果掉落产生新的“生态克制链”，则自动触发连击（无需玩家操作），实现爽快感。

### 四、 Three.js 场景与视觉规划（无代码）

要让3D消消乐比2D更有质感，规划如下：

| 模块 | 技术选型/设计方案 |
| :--- | :--- |
| **相机视角** | 采用 **45度正交视角（OrthographicCamera）** 或 **透视固定视角**。保证棋盘看起来像“立体沙盘”，方便观察前后堆叠。建议采用2.5D固定视角，不启用轨道控制（防止玩家晕眩）。 |
| **棋盘布局** | 采用 **8x8 网格**，但给每个格子增加 **Y轴高度起伏**（模拟田地丘陵感）。棋子用圆柱或方柱垫高，底部带有倒影圆盘。 |
| **3D模型方案** | 不加载外部复杂FBX/GLTF（流量大）。**全用Three.js基础几何体组合（Group）**：<br>- **苹果**：球体 + 圆柱梗。<br>- **鸡**：椭球体（身体）+ 圆锥（喙）+ 球体（头）。<br>- **大象**：大立方体（身体）+ 拉伸圆柱（鼻子）+ 片状耳朵。<br>- **树木**：圆锥（树冠）+ 圆柱（树干）。<br>使用**低多边形（Low Poly）**风格配**柔光材质（MeshPhongMaterial）**，颜色鲜艳。 |
| **灯光与氛围** | 主光源：平行光（模拟日光）。辅光：环境光（提亮暗部）。背光：区域光（勾勒边缘）。背景使用渐变色天空球，搭配漂浮的粒子（模拟花粉或萤火虫）。 |
| **交互反馈** | 使用 **Raycaster（射线检测）** 实现点击拾取。点击棋子时，棋子**向上弹跳 + 发光描边（OutlinePass）**；交换时进行**平滑插值移动（TWEEN或GSAP）**；消除时播放**缩放消失+粒子爆炸**特效（使用PointsMaterial）。 |

### 五、 特殊道具与障碍物拓展

为了让游戏有策略深度，增加以下机制：

1.  **障碍物（不可移动）**：
    - **石头**：占据格子，需使用“锄头”道具或三次普通消除相邻才能打碎。
    - **水洼**：棋子无法掉落穿过，需使用“水桶”道具抽干。
2.  **“农具”的获取方式**：
    - 不直接出现在棋盘上。当玩家**连续触发3次“生态克制”** 时，屏幕下方技能槽充能，点击后可释放对应的农具技能（如镰刀划屏清一排）。

| 关卡类型 | 胜利条件 | 特色限制 |

| **大象狂欢** | 利用大象消除任意 **30个棋子**。 | 初始赠送一个大象，保护好它，不能被交换走。 |

### 七、 总结规划亮点

1. **规则自洽**：将生物学食物链（鸡吃虫、狗咬鸡、大象无敌）完美转化为三消的“配对条件”，比单纯“消消乐”更有教育意义和策略性。
2. **3D表现力**：利用Three.js的物理引擎（或模拟动画），让棋子带有“重力下落”、“弹性跳动”，立体感远强于2D精灵图。
3. **平衡性保障**：由于大象过强，将其设为稀有刷新（每局最多同时存在1个），且不能通过普通交换生成，只能由系统在连击5次后作为奖励生成，防止游戏失衡。

这份规划既保留了经典三消的“上手简单”，又植入了独特的“生态斗兽棋”内核，同时在Three.js技术实现上完全可行（纯Geometry组合 + 基础Shader）。你可以直接按此蓝图启动开发。如有细节需要深挖（如具体动画曲线或粒子颜色搭配），随时告诉我。 🐘🌾
