## 1. 製品定義

| 項目 | 内容 |
|----|------|
| 名称 | 田园消消乐 |
| タイプ | 8×8 三消 + 生態克制 |
| 視点 | 固定 2.5D 直交サンドボックス、回転不可 |
| 操作 | 隣接する2つの駒をクリックして交換（上下左右のみ） |
| プラットフォーム形態 | 自研 H5、游戏大厅から `launch` で開く |
| 成功体験 | 手に取ればすぐ三消ができる；初めて「鶏が虫を食べる」時にルールの進化を感じる；連鎖落下にリズムがある |

**V1 でやらないこと：** ランキングの局内リアルタイム、友人の観戦、駒の育成、オープンワールド、GLTF 精細モデル、プレイヤー自作关卡。

## 2. プレイヤーフロー

```
大厅で「開始」をクリック
  → ロードページ（session を読む）
  → 关卡選択（四关リスト + 残高、P4 で初めて課金を表示）
  → 対局
       HUD：目標 / 手数またはカウントダウン / スコア / combo / スキルスロット
       盤面：クリックで選択 → 隣接をクリックで交換
       消えない：弾き戻し、手数消費なし
       消える：1 手消費 → 消去アニメーション → 落下 → 補子 → 自動連鎖
  → 通关 / 失敗の決済
  → 次の关 / リトライ / 关卡選択へ戻る
```

初回に「豊穣关」へ入ると 3 つのヒントが表示され、スキップ可能、以後は表示されない（localStorage）。

---

## 3. コアループ

1. 目標を見る（あと植物/鶏鴨/木/象踏みがいくつ足りないか）。
2. 同種の3連を探す、または克制者を獲物2匹の隣に動かす。
3. 交換 → 消去 → 落下連鎖。
4. 生態消去は元の格に肥料を残し、次の消去でその格のスコア ×2。
5. 生態を含む決済を連続 3 回行うとスキルスロットが光り、鎌/锄頭/水桶で局面を打開。
6. 目標達成かつ手数/時間が残っている → 勝利。

## 4. 画面

| 画面 | 要素 | 挙動 |
|------|------|------|
| ロード | ゲーム名、進捗 | session が無効なら大厅へ戻るよう案内 |
| 关卡選択 | 四关カード：名称、目標概要、アンロック状況 | V1 は四关すべて開放；P4 で入場費を表示 |
| 対局 HUD 上部 | 关卡名、目標進捗バー、残り手数またはカウントダウン、スコア、combo | カウントダウンは秒刻み、一時停止中は凍結 |
| 対局 HUD 下部 | スキルスロット（最大 2）、一時停止 | 充電未完了のスロットはグレー |
| 盤面 | 8×8 の地块 + 駒 | 選択で弾み+アウトライン；不正格はアウトラインなし |
| 一時停止 | 続行 / リスタート / 放棄 | リスタートは試行を1回消費；放棄は失敗決済 |
| 勝利 | スコア、残り手数、発奖の有無（P4） | 次の关 / 关卡選択へ戻る |
| 失敗 | 原因（手数/時間切れ）、目標の不足数 | リトライ / 关卡選択へ戻る |
| 残高不足 | メッセージ + チャージへ | P4 のみ |

キーボード（P5）：方向キーで選択変更、Enter で選択格の向きの格と交換。V1 はマウス/タッチのみ。

## 5. 操作ルール（プレイヤー視点）

- **直交隣接**かつ双方が移動可能な駒のみ交換できる。
- 石、木、水たまりの格は交換対象にできない。ロックされた大象は換えられない（獲物を隣に換えてくる）。
- 交換後に横または縦に「合法3連」がない → 元に戻し、**手数・時間を消費しない**。
- 合法3連がある → 1 手消費（制限時間关は手数を消費せず、タイマーのみ）。
- 連鎖がすべて再生し終わるまで次のクリックを受け付けない；連鎖中の盤面クリックは無効。
- 斜めの3連はカウントしない。L / T 形の交差は各格を1回だけ消去。

## 6. 3種類の消去（機能）

優先度：**大象 > 生態 > 同種**。一行は最高優先度のルールで1回だけスコア計算。

### 6.1 同種

3つ以上**同一種**が一線に並ぶ。例：りんご-りんご-りんご。

| 長さ | プレイヤーが見る結果 |
|------|----------------|
| 3 | 縮小して消滅、基礎点 |
| 4 | 消滅、中心格に肥料出現 |
| 5+ | 消滅、スキルスロット +1 充電（关卡で許可されたスキルの制限あり） |

### 6.2 生態（捕食）

一線に**ちょうど 1 体の克制者**がいて、残りはすべてその獲物、獲物は同種である必要はない。例：鶏-蚂蚁-瓢虫。

| 克制者 | 食べられる | 食べられない |
|--------|------|--------|
| 鶏、鴨、鵝 | 花、菜、果、虫 | 五谷 |
| 犬 | 鶏、鴨、鵝、鳩などの家禽 | 植物、虫 |
| 豚 | 木、花、菜、果、虫、五谷 | 犬 |
| 牛、馬 | 花、五谷、樹苗 | 虫、肉 |
| 大象 | 6.3 参照 | 障害、農具 |

プレイヤーが見るもの：捕食アニメーション → 3つの格がすべて空になる（V1 は克制者も一緒に退場）→ 克制者の元の格に肥料が残る。

### 6.3 大象

一線に象 1 体 + 残り2格が任意の消去可能な駒 → 3格をクリア、陣営を無視。盤上は最大 1 体の象。普通の交換から「合成」されることはない；連撃 5 回でシステムが空の頂格に落下させるか、关卡の開局配置による。

## 8. 关卡仕様

勝敗は**一連の連鎖アニメーション終了後**に決済する。

### 8.1 豊穣关

- プール：小麦、水稻、玉米、白菜、西红柿、苹果、鸡、鸭；蚂蚁/瓢虫は低ウェイト。
- 勝：20 手以内に植物角色（五谷+菜+果+花）を **50** 個消去。鶏鴨が消されてもカウントされない。
- 負：手数 0 で目標未達。
- スキル：鎌（充電後に使用可）。
- チュートリアル：①隣接クリックで交換 ②3つ同じで消える ③鶏は隣の虫2匹/菜/果を食べられるが、麦は食べない。

### 8.2 追い払い关

- プール：鸡、鸭、鹅、鸽、狗。植物なし。
- 勝：**90 秒**以内に**犬の生態消去**で家禽を 15 羽消す。
- 負：時間切れ。
- **同種で鶏3羽を消しても目標に数えない**（犬が家禽を食べる生態を成立させる必要がある）。
- スキル：なし。一時停止でタイマー凍結。

### 8.3 破壊王关

- プール：小麦、苹果、玫瑰、猪（低ウェイト）。固定で松樹 3 本、HP=5、交換不可、落下での通過不可。
- 勝：3 本の木の HP をゼロにする。
- 負：25 手を使い切る。
- 木の減血：豚の生態（木が獲物 run に入る）-2；豚3匹一線で **3×3 拱撃** 発動（範囲内の木 -5）；锄頭で単体 -3；普通の隣接三消 -1。
- スキル：锄頭。

### 8.4 大象狂欢

- プール：小麦、苹果、鸡、狗、猪。開局中央付近にロック象 1 体。
- 勝：**大象ルール**で 30 格を消去（同種/生態はこの目標に数えない）。
- 負：30 手を使い切る。
- 2体目の象は刷らない。プレイヤーは獲物を象の両側または上下に換えてくる。
- スキル：なし。

## 9. 障害、肥料、スキル

| 機能 | プレイヤーの感知 | ルール |
|------|----------|------|
| 石 | 灰色でクリック不可 | HP3；隣接で消去があるたび -1；锄頭で一撃 |
| 木 | 大きいモデルでクリック不可 | 破壊王を参照 |
| 水たまり | 格面が反射 | 上の駒は水たまりの一格上で停止；水桶で吸い出したら落下再開 |
| 肥料 | 格面に一かたまりの暗色 | その格が次に消されるとスコア ×2、その後消滅 |
| 鎌 | 下部バーのアイコン | 1行または1列を選択、植物のみクリア、手数消費なし、充電 1 消費 |
| 锄頭 | 下部バーのアイコン | 石または木を 1 つクリック |
| 水桶 | 下部バーのアイコン | 水たまり 1 格をクリック |

充電：1回のプレイヤー操作で発生した一連の決済の中に生態消去が一度でもあればカウント +1；3 で 1 スロット獲得、上限 2。5 連の同種も +1 スロット（生態充電とスロットを共用）。

V1 の豊穣に石・水たまりなし；破壊王に水たまりなし。水たまりは図鑑に残し、四关の本線をブロックしない。

## 10. スコアと経済

```
同種     10 × 消した数 × combo × 肥料
生態     25 × 消した数 × combo × 肥料
大象     40 × 消した数 × combo
スキル清格  8 × 消した数
障害破壊   20 × 破壊数
```

combo：今回の操作で最初の消去が 1、連鎖のラウンドごとに +1；プレイヤーの次の手動操作で 1 に戻る。

**P4 ウォレット：**

- 关卡選択開始で入場費を引き落とす（デフォルトは各关 1 ゲームコイン）。
- 通关は星で決済：残り資源 ≥50% で三星、≥20% で二星、それ以外は一星；報酬 2 / 3 / 5（設定可）。
- 失敗時は入場費を返さない。
- 1つも入れ替えずに退出した場合 → 返金。
- 残高不足では開局できない。

V1（P0–P3）は課金なし、ローカルで直接遊べる。

## 12. 境界（必ず固定する）

1. 図鑑は大きくてよいが、**単关のリフレッシュ種類 ≤ 8**。
2. 農具は盤面に載せない。
3. 鶏は五谷を食べない：一線「鶏+麦+麦」は生態でも同種でもなく、弾き戻す。
4. 犬は植物を食べない；豚は犬を拱かない。
5. 盤上は同時に最大 1 体の象。
6. 連鎖再生中は入力を破棄。
7. 勝敗はアニメーション途中で判定しない。
8. V1 は克制者と獲物が一緒に退場。
9. 追い払い关は制限時間 90 秒、手数は使わない。
10. 水たまりは四关の本線に入れない。
