### 二、핵심 규칙 확장（"생태 상성 체인" 설계）

당신의 규칙 로직의 본질은 **"지향 소거"**입니다. 전통적인 3매치（셋이 같으면 소거）를 기반으로, **"포식/상성 매칭"**을 내장했습니다. 플레이어가 **상성자**와 **피상성자**를 한 줄(또는 특정 도형)로 만들면 고급 소거가 발동됩니다.

다음은 확장한 **완전한 상성 매트릭스**입니다（A가 B를 상성）:

| 상성자 (A) | 상성 방식 | 피상성자 (B) | 확장 규칙 설명 |
| :--- | :--- | :--- | :--- |
| **닭, 오리, 거위** | 쪼아먹기 / 포식 | 화초, 채소·과일, 곤충（개미/무당벌레/애벌레） | 보충: 이들은 **오곡을 먹지 않습니다**（곡식이 너무 단단해서 따로 소거해야 함）. |
| **개** | 물어뜯기 | 닭, 오리, 거위, 비둘기 | 개는 가금을 물 뿐만 아니라 **뼈도 뜯습니다（돼지/소/말 뼈에 대응）**, 다만 게임에서는 단순화해 모든 중소형 가금을 상성합니다. |
| **돼지** | 받아 뒤집기 / 훼손 | 나무, 화초, 채소·과일, 곤충, **모든 오곡 작물** | 돼지는 파괴왕입니다. 보충: 돼지는 개를 **받지 않습니다**（개가 돼지를 물 수 있기 때문에）, 상성 폐루프 형성. |
| **소, 말** | 뜯어먹기 / 밟기 | 화초, **오곡 작물**, 과수 묘목 | 보충: 소·말은 초식 대형 가축으로 작물을 전용으로 상성하지만 곤충과 고기는 먹지 않습니다. |
| **코끼리** | 절대 압제（밟기/휘두르기） | **코끼리 외 모든 요소（돼지·개·소·말 포함）** | 코끼리는 최고 전력입니다. 밸런스 보충: 코끼리는 "농기구"（아이템）를 소거할 수 **없고**, 보드에 출현 확률이 매우 낮습니다（희귀 말）. |
| **낫（아이템）** | 수확 | 모든 오곡 작물, 화초 | 가로줄 또는 세로줄의 모든 식물 계열을 일회성 소거. |
| **괭이（아이템）** | 부수기 | 나무, 돌（장애물） | 두꺼운 체력 장애물 전용 제거. |

### 三、플레이 메커니즘 설계（"소소락"을 어떻게 조작하는가）

Three.js의 3D 씬에서 **"클릭 교환 + 생태 판정"** 융합 모드를 채택합니다:

1. **기본 조작**: 플레이어가 인접한 두 3D 말을 클릭해 위치를 교환합니다.
2. **판정 로직（핵심）**:
    - **동종 소거**: 교환 후 가로·세로에 **≥3개 같은 말**이 있으면 기초 소거 실행（예: 사과 3개）.
    - **생태 소거（특수）**: 교환 후 가로·세로에 **"상성자 + 임의 피상성자 2개"**（예: 닭 + 벌레 + 벌레）가 있으면, **셋이 같을 필요 없이** 바로 "포식 애니메이션"이 발동합니다. 닭이 벌레를 먹고 추가 점수를 얻으며, 해당 칸에 **"분변 비료"**（버프, 다음 소거 점수 2배）가 생성됩니다.
    - **코끼리 특권**: 코끼리가 **임의 서로 다른 말 2개**와 한 줄을 이루면 "괴롭힘" 효과가 발동해, 종족을 무시하고 그 세 칸을 바로 비웁니다.
3. **연쇄 반응（Combo）**: 말이 소거된 후 위에서 떨어져 채워집니다. 떨어진 결과 새로운 "생태 상성 체인"이 만들어지면 자동으로 연타가 발동합니다（플레이어 조작 불필요）, 쾌감 구현.

### 四、Three.js 씬과 시각 설계（코드 없음）

3D 소소락이 2D보다 질감 있게 하기 위한 설계는 다음과 같습니다:

| 모듈 | 기술 선정/설계 방안 |
| :--- | :--- |
| **카메라 시점** | **45도 직교 시점（OrthographicCamera）** 또는 **원근 고정 시점** 채택. 보드가 "입체 모형판"처럼 보이게 해 전후 겹침을 쉽게 관찰할 수 있습니다. 2.5D 고정 시점 권장, 궤도 제어 비활성화（플레이어 어지럼증 방지）. |
| **보드 레이아웃** | **8x8 그리드** 채택, 각 칸에 **Y축 높이 기복** 추가（밭 구릉 느낌 시뮬레이션）. 말은 원기둥/사각기둥으로 받치고 바닥에 반사 원판. |
| **3D 모델 방안** | 외부 복잡 FBX/GLTF 로드 없음（트래픽 큼）. **전부 Three.js 기본 도형 조합（Group）**:<br>- **사과**: 구체 + 원기둥 꼭지.<br>- **닭**: 타원체（몸）+ 원뿔（부리）+ 구체（머리）.<br>- **코끼리**: 큰 정육면체（몸）+ 늘린 원기둥（코）+ 판 모양 귀.<br>- **나무**: 원뿔（수관）+ 원기둥（줄기）.<br>**로우 폴리（Low Poly）** 스타일에 **부드러운 광택 재질（MeshPhongMaterial）**, 화려한 색상. |
| **조명과 분위기** | 주광: 평행광（햇빛 시뮬레이션）. 보조광: 환경광（어두운 부분 밝히기）. 역광: 영역광（윤곽 강조）. 배경은 그라데이션 하늘 구체 + 떠다니는 입자（꽃가루나 반딧불 시뮬레이션）. |
| **상호작용 피드백** | **Raycaster（레이 검출）**로 클릭 픽업 구현. 말 클릭 시 **위로 튀어오름 + 발광 윤곽（OutlinePass）**; 교환 시 **부드러운 보간 이동（TWEEN 또는 GSAP）**; 소거 시 **축소 소멸 + 입자 폭발** 이펙트（PointsMaterial 사용）. |

### 五、특수 아이템과 장애물 확장

게임에 전략 깊이를 주기 위해 다음 메커니즘을 추가합니다:

1. **장애물（이동 불가）**:
    - **돌**: 칸을 점유하며, "괭이" 아이템 또는 인접 소거 3회로 부숴야 함.
    - **웅덩이**: 말이 떨어져 통과할 수 없으며, "물통" 아이템으로 물을 빼야 함.
2. **"농기구" 획득 방식**:
    - 보드에 직접 등장하지 않습니다. 플레이어가 **"생태 상성"을 연속 3회** 발동하면 화면 아래 스킬 게이지가 충전되고, 클릭하면 해당 농기구 스킬을 방출합니다（예: 낫으로 화면 한 줄 긁어 소거）.

### 六、스테이지와 목표 설계

| 스테이지 유형 | 승리 조건 | 특징 제한 |
| :--- | :--- | :--- |
| **풍년 스테이지** | 20수 내에 **오곡/채소·과일 50개** 소거. | 보드에 닭·오리·거위가 다수 등장해 식물 소거를 방해. |

| **파괴왕 스테이지** | **돼지**로 **큰 나무 3그루**를 받아 넘기기（나무 체력 5포인트）. | 돼지 출현 확률 낮음, 돼지 3마리를 모아야 범위 받아치기 발동. |
| **코끼리 축제** | 코끼리로 임의 **말 30개** 소거. | 초기 코끼리 1마리 지급, 잘 보호해야 하며 교환으로 빼앗기면 안 됨. |

### 七、설계 하이라이트 요약

1. **규칙 자기정합**: 생물학적 먹이사슬（닭이 벌레 먹기, 개가 닭 물기, 코끼리 무적）을 3매치의 "매칭 조건"으로 완벽하게 전환, 단순 "소소락"보다 교육적이고 전략적입니다.
2. **3D 표현력**: Three.js의 물리 엔진（또는 시뮬레이션 애니메이션）으로 말이 "중력 낙하", "탄성 점프"를 갖게 해, 입체감이 2D 스프라이트보다 훨씬 강합니다.
3. **밸런스 보장**: 코끼리가 너무 강하므로 희귀 리젠으로 설정（한 판에 최대 동시 1마리）, 일반 교환으로는 생성할 수 없고 오직 시스템이 연타 5회 후 보상으로만 생성, 게임 불균형 방지.

이 설계는 고전 3매치의 "쉬운 조작"을 유지하면서 독특한 "생태 투계 바둑" 코어를 심었고, Three.js 기술 구현 측면에서도 완전히 실현 가능합니다（순수 Geometry 조합 + 기초 Shader）. 이 청사진대로 바로 개발을 시작하면 됩니다. 세부 사항（구체 애니메이션 커브나 입자 색상 조합 등）을 더 파고싶다면 언제든 말씀하세요. 🐘🌾
