## 1. Как пользоваться тремя документами

| Документ | Отвечает на вопрос | Не отвечает |

## 2. Объём V1

**Считается готовым к релизу, когда:** четыре уровня проходимы, три вида удаления, навыки и препятствия «Разрушителя», H5 открывается из зала. Кошелёк можно выключить (переключатель `xxl.entry_bet`).

**Явно вырезано или отложено:** 100 видов одновременно на доске, инструменты как фигуры, физический движок, GLTF, наблюдение, рейтинги в партии, лужа в основной линии, «сдерживающий остаётся после еды», серверная валидация каждого хода.

## 4. Этапы и зависимости

```
P0 同种三消 ─────────┐
P1 选关与丰收 ───────┼─ P2 生态与驱赶 ─ P3 障碍农具 ─ P4 象+钱包 ─ P5 抛光
渲染沙盘（可与 P0 并行）┘
```

- P0 не зависит от PHP. Играется локально через `?debug=1`.
- P1 не зависит от кошелька.
- P2 зависит от расширения сканера совпадений P0, способ операций не меняется.
- P3 зависит от overlay клеток.
- P4 зависит от существующих на платформе `POST /api/game/launch` и `SelfProvider`; на стороне игры добавляются ticket, bet, settle.
- P5 функциональных зависимостей не имеет, переключатель слабых устройств можно вставить когда угодно.

## 5. Рабочие пакеты (по ролям)

**A. Домен (без интерфейса)**
JSON-галерея → снимок доски → совпадения (один вид/экология/слон) → гравитация → победа/поражение уровня → очки. Vitest — раньше картинки.

**B. Отображение**
Сцена, камера, из 10 шаблонов сначала 3 (колос/фрукт/курица), Raycaster, easing обмена и удаления. HUD на DOM.

**C. Контент уровней**
JSON четырёх уровней: пул выпадения, цель, шаги/лимит времени, белый список навыков, стартовые препятствия.

**D. Платформа**
Параметры URL launch, показ баланса, bet/settle, стратегия возврата при провале, события play-log.

Рекомендуемый порядок: красные/зелёные тесты P0 в A → B подключает снимок → C «Урожай» → тесты экологии в A → остальные три уровня в C → D.

## 6. Что трогать на стороне платформы (только P4)

Контракт интерфейсов — в **[api.ru.md](api.ru.md)**. Точки изменений платформы:

| Пункт | Сейчас | Планируемое действие |
|----|------|----------|
| Игровые записи | `GameController::launch` уже пишет session | в админке добавить запись type=self, api_endpoint указывает на этот H5 |
| Кошелёк | `SelfProvider::bet/settle` уже есть | игра вызывает по round_id; задать верхний предел выплаты за раунд |
| Функциональные переключатели | `FeatureFlag` уже есть | `xxl.eco_chain` `xxl.elephant` `xxl.skills` `xxl.entry_bet` |
| Статический хостинг | Nginx уже раздаёт | `/games/xiaoxiaole/` указывает на артефакты сборки |
| Открытие из зала | Flutter `launchUrl` | к endpoint добавляется `session_id` |

P0–P3 **не требуют правки PHP**.

## 7. Риски

| Риск | Влияние | Контрмеры |
|------|------|------|
| Экологические правила непонятны игроку | «Выгон» не пройти | третья подсказка обучения; превью удаляемого отложено в P5 |
| Видов в пуле всё ещё много | нечего удалять | жёсткий предел 8 видов на уровень |
| Слон слишком силён | «Карнавал» пустеет мгновенно | в цель идёт только правило слона; на доске жёстко 1 |
| Клиент подделывает очки ради награды | кошелёк | лимит выплаты P4; проверка записи позже |
| Слабые устройства теряют кадры | впечатление | верхний предел dpr 2; частицы можно отключить |

## 8. Принято (больше не спрашивать)

- После экологии сдерживающий уходит **вместе** с добычей.
- «Выгон» — **90 секунд лимита**, без шагов.
- Лужа не входит в основную линию четырёх уровней.
- V1 спавнит только таблицу из раздела 7 функционального дизайна; остальные виды — только в файл галереи.

Чтобы изменить эти четыре пункта, сначала правь `functional-design.ru.md`, потом код.
