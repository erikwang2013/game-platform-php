### 二、 コアルールの拡張（「生態克制チェーン」設計）

あなたのルールロジックの本質は**「定向消去」**です。従来の三消（3つ同じで消去）の上に、**「捕食/克制マッチング」**を埋め込みます。プレイヤーが**克制者**と**被克制者**を3つ一列（または特定の図形）に揃えると、高級消去が発動します。

以下は私が拡張した**完全な克制マトリクス**（A は B を克制）です：

| 克制者 (A) | 克制方式 | 被克制者 (B) | 拡張ルール説明 |
| :--- | :--- | :--- | :--- |
| **鶏、鴨、鵝** | 啄食 / 捕食 | 花草、野菜果物、昆虫（蚂蚁/瓢虫/毛毛虫） | 補足：彼らは**五谷（穀物）を食べない**。穀粒が硬すぎるため、別途消去が必要。 |
| **犬** | 噛み裂く | 鶏、鴨、鵝、鳩 | 犬は家禽を噛むだけでなく、**犬は骨も噛む（猪/牛/馬の骨に相当）** が、ゲームでは簡略化し、すべての中小型家禽を克制する。 |
| **豚** | 拱く / 荒らす | 樹木、花草、野菜果物、昆虫、**すべての五谷の穀物** | 豚は破壊王。補足：豚は**犬を拱かない**（犬が豚を噛むため）、克制の閉ループを形成。 |
| **牛、馬** | 齧る / 踏みつける | 花草、**五谷の穀物**、果樹の苗 | 牛馬は草食の大牲口として、農作物を専門に克制するが、昆虫と肉類は食べない。 |
| **大象** | 絶対的圧制（踏む/投げる） | **大象以外のすべての元素（猪狗牛馬を含む）** | 大象は最強戦力。バランスのため、補足：大象は**「農具」（道具）を消せない**、かつ大象の盤面出現確率は極めて低い（レア駒）。 |
| **鎌（道具）** | 刈り取り | すべての五谷の穀物、花草 | 横列または縦列のすべての植物系を一括クリア。 |
| **锄頭（道具）** | 叩き壊す | 樹木、石（障害） | 高HP障害物を専門に除去。 |

### 三、 玩法メカニズム設計（「消消乐」の操作方法）

Three.jsの3Dシーンでは、**「クリック交換+生態判定」**の融合モードを採用します：

1.  **基本操作**：プレイヤーは隣接する2つの3D駒をクリックして位置を交換します。
2.  **判定ロジック（要）**：
    - **同種消去**：交換後、横または縦に **≥3個の同じ駒** が並んだら、基本消去を実行（例：りんご3つ）。
    - **生態消去（特殊）**：交換後、横または縦に **「克制者 + 任意の被克制者2つ」** が並んだら（例：鶏 + 虫 + 虫）、**3つがすべて同じである必要はなく**、即座に「捕食アニメーション」が発動し、鶏が虫を食べ、追加加点されます。さらにその格子には**「糞肥料」**（增益buff、次の消去のスコア2倍）が生成されます。
    - **大象特権**：大象と**任意の異なる駒2つ**が一列に並ぶと、「いじめ」効果が発動し、種族を無視してその3つの格子を直接クリアします。
3.  **連鎖反応（Combo）**：駒消去後、上から落下して補充されます。落下で新しい「生態克制チェーン」が生まれたら、自動的に連撃が発動（プレイヤー操作不要）、爽快感を実現します。

### 四、 Three.js シーンとビジュアル計画（コードなし）

3D消消乐を2Dより質感のあるものにするため、以下のように計画します：

| モジュール | 技術選定/設計案 |
| :--- | :--- |
| **カメラ視点** | **45度直交視点（OrthographicCamera）** または **透視固定視点** を採用。盤面が「立体サンドボックス」のように見え、前後の重なりを観察しやすい。2.5D固定視点を推奨、軌道コントロールは有効化しない（プレイヤーの目まい防止）。 |
| **盤面レイアウト** | **8x8 グリッド** を採用、ただし各格子に **Y軸の高低差** を追加（田畑の丘陵感をシミュレート）。駒は円柱または角柱でかさ上げし、底面に反射ディスクを設置。 |
| **3Dモデル案** | 外部の複雑なFBX/GLTFを読み込まない（トラフィック大）。**すべてThree.jsの基本幾何体の組み合わせ（Group）** を使用：<br>- **りんご**：球体 + 円柱の軸。<br>- **鶏**：楕円体（体）+ 円錐（くちばし）+ 球体（頭）。<br>- **大象**：大きい立方体（体）+ 引き伸ばした円柱（鼻）+ 板状の耳。<br>- **樹木**：円錐（樹冠）+ 円柱（幹）。<br>**低ポリゴン（Low Poly）** スタイルに**柔らかなライティング材質（MeshPhongMaterial）**、鮮やかな配色。 |
| **ライティングと雰囲気** | 主光源：平行光（太陽光を模す）。補助光：環境光（暗部を明るく）。バックライト：エリアライト（エッジを縁取る）。背景はグラデーションの空球、浮遊パーティクル（花粉や蛍を模す）。 |
| **インタラクション** | **Raycaster（レイ検出）** でクリックピッキングを実装。駒クリック時に、駒は**上に弾む + 発光アウトライン（OutlinePass）**；交換時は**スムーズな補間移動（TWEENまたはGSAP）**；消去時は**スケール消失+パーティクル爆発**エフェクト（PointsMaterial使用）。 |

### 五、 特殊道具と障害物の拡張

ゲームに戦略の深みを持たせるため、以下のメカニズムを追加します：

1.  **障害物（移動不可）**：
    - **石**：格子を占有、破壊には「锄頭」道具または隣接する普通消去を3回必要とする。
    - **水たまり**：駒は落下で通過できない、「水桶」道具で吸い出す必要がある。
2.  **「農具」の入手方法**：
    - 盤面には直接出現しない。プレイヤーが**連続3回「生態克制」** を発動すると、画面下のスキルスロットが充電され、クリックで対応する農具スキルを発動できる（例：鎌をスワイプして一列クリア）。

### 七、 企画のハイライトまとめ

1. **ルールの自己整合**：生物学的な食物連鎖（鶏は虫を食べ、犬は鶏を噛み、大象は無敵）を三消の「ペア条件」に見事に転換し、単なる「消消乐」より教育性と戦略性が高い。
2. **3D表現力**：Three.jsの物理エンジン（または模擬アニメーション）を活用し、駒に「重力落下」「弾性バウンド」を持たせ、立体感は2Dスプライトよりはるかに強い。
3. **バランス保証**：大象が強すぎるため、レアなリフレッシュに設定（1局あたり同時に存在するのは最大1体）、かつ普通の交換では生成できず、システムが連撃5回後に報酬としてのみ生成し、ゲームバランスの崩壊を防ぐ。

この計画は古典的な三消の「入門の簡単さ」を保ちつつ、独自の「生態斗兽棋」コアを埋め込み、Three.js技術実装も完全に実現可能（純粋なGeometry組み合わせ + 基本Shader）です。この青写真に従って直接開発を開始できます。詳細を深掘りしたい場合（具体的なアニメーションカーブやパーティクルの配色など）、いつでもお知らせください。 🐘🌾
