---

## 1. 产品定义

| 项 | 内容 |
|----|------|
| 名称 | 田园消消乐 |
| 类型 | 8×8 三消 + 生态克制 |
| 视角 | 固定 2.5D 正交沙盘，不可旋转 |
| 操作 | 点击两枚相邻棋子交换（仅上下左右） |
| 平台形态 | 自研 H5，从游戏大厅 `launch` 打开 |
| 成功体验 | 上手即会三消；第一次「鸡吃虫」时感到规则升级；连锁掉落有节奏 |

**V1 不做：** 排行榜局内实时、好友观战、棋子养成、开放世界、GLTF 精模、玩家自定义关卡。

---

## 2. 玩家流程

```
大厅点「开始」
  → 加载页（读 session）
  → 选关（四关列表 + 余额，P4 才显示扣费）
  → 对局
       HUD：目标 / 步数或倒计时 / 分数 / combo / 技能槽
       棋盘：点击选中 → 点相邻交换
       无消：弹回，不扣步
       有消：扣 1 步 → 消除动画 → 下落 → 补子 → 自动连锁
  → 通关 / 失败结算
  → 下一关 / 重试 / 回选关
```

首次进入「丰收关」弹出 3 条提示后消失，可跳过，不再出现（localStorage）。

---

## 3. 核心循环

1. 看目标（还差多少植物 / 鸡鸭 / 树 / 象踩格）。
2. 找同种三连，或把克制者挪到两只猎物旁边。
3. 交换 → 消除 → 掉落连锁。
4. 生态消除在原格留下肥料，下一消该格得分 ×2。
5. 连做 3 次带生态的结算，技能槽亮，用镰刀/锄头/水桶解局。
6. 目标满且步数/时间仍有余 → 胜利。

## 4. 界面

| 界面 | 元素 | 行为 |
|------|------|------|
| 加载 | 游戏名、进度 | session 无效则提示回大厅 |
| 选关 | 四关卡片：名称、目标摘要、是否解锁 | V1 四关全开；P4 显示入场费 |
| 对局 HUD 顶 | 关卡名、目标进度条、剩余步数或倒计时、分数、combo | 倒计时走秒，暂停时冻结 |
| 对局 HUD 底 | 技能槽（最多 2）、暂停 | 未充能时槽位灰 |
| 棋盘 | 8×8 地块 + 棋子 | 选中弹跳+描边；非法格无描边 |
| 暂停 | 继续 / 重开 / 放弃 | 重开耗一次尝试；放弃失败结算 |
| 胜利 | 分数、剩余步数、是否发奖（P4） | 下一关 / 回选关 |
| 失败 | 原因（步数/超时）、目标差多少 | 重试 / 回选关 |
| 余额不足 | 文案 + 去充值 | 仅 P4 |

键盘（P5）：方向键改选，Enter 与选中格的朝向格交换。V1 只做鼠标/触摸。

## 5. 操作规则（玩家视角）

- 只能交换**正交相邻**且双方都可移动的棋子。
- 石头、树、水洼格不能作为交换对象。锁定的大象不能被换走（猎物换过来）。
- 交换后横或竖没有「合法三连」→ 换回，**不扣步、不扣时**。
- 有合法三连 → 扣 1 步（限时关不扣步，只走表）。
- 连锁全部播完才接受下一次点击；连锁中点棋盘无效。
- 斜向三连不算。L / T 形相交只消一次各格。

---

## 6. 三种消除（功能）

优先级：**大象 > 生态 > 同种**。一行只按最高优先级算一次分。

### 6.1 同种

三个及以上**同一物种**连成一线。例：苹果-苹果-苹果。

| 长度 | 玩家看到的结果 |
|------|----------------|
| 3 | 缩小消失，基础分 |
| 4 | 消失，中心格出现肥料 |
| 5+ | 消失，技能槽 +1 充能（受关卡允许的技能限制） |

### 6.2 生态（捕食）

一线里**恰好 1 个克制者**，其余都是它的猎物，猎物不必同种。例：鸡-蚂蚁-瓢虫。

| 克制者 | 能吃 | 不能吃 |
|--------|------|--------|
| 鸡、鸭、鹅 | 花、菜、果、虫 | 五谷 |
| 狗 | 鸡、鸭、鹅、鸽等家禽 | 植物、虫 |
| 猪 | 树、花、菜、果、虫、五谷 | 狗 |
| 牛、马 | 花、五谷、树苗 | 虫、肉 |
| 大象 | 见 6.3 | 障碍、农具 |

玩家看到：捕食动画 → 三个格子都空掉（V1 克制者一起离场）→ 克制者原格留下肥料。

### 6.3 大象

一线含 1 只象 + 另外两格任意可消棋子 → 三格清空，无视阵营。盘上最多 1 只象。不会从普通交换「合成」出来；连击达到 5 由系统掉落到空顶格，或关卡开局放置。

## 8. 关卡规格

胜负在**整段连锁动画结束**后结算。

### 8.1 丰收关

- 池：小麦、水稻、玉米、白菜、西红柿、苹果、鸡、鸭；蚂蚁/瓢虫低权重。
- 胜：20 步内消除 **50** 个植物角色（五谷+菜+果+花）。鸡鸭被消不计入。
- 负：步数为 0 且目标未满。
- 技能：镰刀（充能后可用）。
- 教学：①点相邻交换 ②三个一样会消 ③鸡可以吃旁边两只虫/菜/果，但不吃麦子。

### 8.2 驱赶关

- 池：鸡、鸭、鹅、鸽、狗。无植物。
- 胜：**90 秒**内用**狗的生态消除**清掉 15 只家禽。
- 负：超时。
- **同种消三只鸡不计入目标**（必须完成狗吃家禽的生态）。
- 技能：无。暂停冻结计时。

### 8.3 破坏王关

- 池：小麦、苹果、玫瑰、猪（低权重）。固定 3 棵松树，HP=5，不可换、不可掉落穿过。
- 胜：3 棵树 HP 归零。
- 负：25 步用尽。
- 树掉血：猪生态（树在猎物 run 里）-2；三只猪一线触发 **3×3 拱击**（树在范围内 -5）；锄头对单棵 -3；普通相邻三消 -1。
- 技能：锄头。

### 8.4 大象狂欢

- 池：小麦、苹果、鸡、狗、猪。开局中央附近 1 只锁定象。
- 胜：由**大象规则**消除 30 格（同种/生态不计入该目标）。
- 负：30 步用尽。
- 不刷第二只象。玩家把猎物换到象两侧或上下。
- 技能：无。

## 9. 障碍、肥料、技能

| 功能 | 玩家感知 | 规则 |
|------|----------|------|
| 石头 | 灰色不可点 | HP3；相邻有消除 -1；锄头一次砸掉 |
| 树 | 高大模型不可点 | 见破坏王 |
| 水洼 | 格面反光 | 上方棋子落到水洼上一格停止；水桶抽干后下落恢复 |
| 肥料 | 格面一摊深色 | 该格下一次被消得分 ×2，随后消失 |
| 镰刀 | 底栏图标 | 选一行或一列，只清植物，不耗步，耗 1 充能 |
| 锄头 | 底栏图标 | 点 1 个石头或树 |
| 水桶 | 底栏图标 | 点 1 格水洼 |

充能：一次玩家操作引发的整段结算里，只要出现过生态消除，计数 +1；到 3 获得 1 槽，上限 2。5 连同种也会 +1 槽（与生态充能共用槽位）。

V1 丰收无石头水洼；破坏王无水洼。水洼留在图鉴，不阻塞四关主线。

## 10. 分数与经济

```
同种     10 × 消掉数 × combo × 肥料
生态     25 × 消掉数 × combo × 肥料
大象     40 × 消掉数 × combo
技能清格  8 × 消掉数
破障碍   20 × 破碎数
```

combo：本次操作第一次消为 1，每多一轮连锁 +1；玩家下一次手操归 1。

**P4 钱包：**

- 选关开始扣入场费（默认每关 1 游戏币）。
- 通关按星结算：剩余资源 ≥50% 三星、≥20% 二星、否则一星；奖励 2 / 3 / 5（可配）。
- 失败不退入场费。
- 一颗子都没换就退出 → 退费。
- 余额不足不能开局。

V1（P0–P3）无扣费，本地可直接玩。

## 12. 边界（必须写死）

1. 图鉴可以很大，**单关刷新种类 ≤ 8**。
2. 农具不上棋盘。
3. 鸡不吃五谷：一线「鸡+麦+麦」不是生态，也不是同种，弹回。
4. 狗不吃植物；猪不拱狗。
5. 盘上同时最多 1 象。
6. 连锁播放期间输入丢弃。
7. 胜负不在动画中途判定。
8. V1 克制者与猎物一同离场。
9. 驱赶关限时 90 秒，不用步数。
10. 水洼不进四关主线。
