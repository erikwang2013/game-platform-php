## 1. 제품 정의

| 항목 | 내용 |
|----|------|
| 이름 | 전원 소소락 |
| 유형 | 8×8 3매치 + 생태 상성 |
| 시점 | 고정 2.5D 직교 사판, 회전 불가 |
| 조작 | 인접 말 2개 클릭 교환（상하좌우만） |
| 플랫폼 형태 | 자체 개발 H5, 게임 로비 `launch`로 열기 |
| 성공 경험 | 잡자마자 3매치 가능; 첫 「닭이 벌레 먹기」에서 규칙 업그레이드 체감; 연쇄 낙하에 리듬 |

**V1에서 안 함:** 랭킹 국내 실시간, 친구 관전, 말 육성, 오픈 월드, GLTF 정밀 모델, 플레이어 커스텀 스테이지.

## 2. 플레이어 흐름

```
로비에서 「시작」 클릭
  → 로딩 페이지（session 읽기）
  → 스테이지 선택（네 스테이지 목록 + 잔액, P4부터 차감 표시）
  → 대국
       HUD: 목표 / 스텝 또는 카운트다운 / 점수 / combo / 스킬 슬롯
       보드: 클릭 선택 → 인접 교환 클릭
       무소거: 되돌아감, 스텝 미차감
       유소거: 1스텝 차감 → 소거 애니메이션 → 낙하 → 보충 → 자동 연쇄
  → 클리어 / 실패 정산
  → 다음 스테이지 / 재시도 / 스테이지 선택 복귀
```

「풍년 스테이지」 최초 진입 시 힌트 3줄이 나왔다 사라지며, 건너뛰기 가능하고 다시 나오지 않음（localStorage）.

---

## 3. 핵심 루프

1. 목표 확인（식물/닭·오리/나무/코끼리 밟기 칸이 얼마나 남았나）.
2. 동종 3연결을 찾거나, 상성자를 사냥감 2마리 옆으로 옮기기.
3. 교환 → 소거 → 낙하 연쇄.
4. 생태 소거는 원래 칸에 비료를 남기고, 다음 소거에서 그 칸 점수 ×2.
5. 생태 포함 정산을 연속 3번 하면 스킬 슬롯이 켜지고, 낫/괭이/물통으로 국면 해소.
6. 목표 달성 + 스텝/시간이 아직 남음 → 승리.

## 4. 인터페이스

| 인터페이스 | 요소 | 동작 |
|------|------|------|
| 로딩 | 게임명, 진행도 | session 무효 시 로비 복귀 안내 |
| 스테이지 선택 | 네 스테이지 카드: 이름, 목표 요약, 해금 여부 | V1 네 스테이지 전부 개방; P4에 입장료 표시 |
| 대국 HUD 상단 | 스테이지명, 목표 진행 바, 남은 스텝 또는 카운트다운, 점수, combo | 카운트다운 초 단위, 일시정지 시 정지 |
| 대국 HUD 하단 | 스킬 슬롯（최대 2）, 일시정지 | 미충전 시 슬롯 회색 |
| 보드 | 8×8 지형 + 말 | 선택 시 튀어오름+윤곽; 불법 칸은 윤곽 없음 |
| 일시정지 | 계속 / 다시 시작 / 포기 | 다시 시작은 시도 1회 소모; 포기는 실패 정산 |
| 승리 | 점수, 남은 스텝, 보상 발급 여부（P4） | 다음 스테이지 / 스테이지 선택 복귀 |
| 실패 | 사유（스텝/시간 초과）, 목표 얼마나 부족한지 | 재시도 / 스테이지 선택 복귀 |
| 잔액 부족 | 문구 + 충전하러 가기 | P4만 |

키보드（P5）: 방향키로 재선택, Enter는 선택 칸의 마주보는 칸과 교환. V1은 마우스/터치만.

## 5. 조작 규칙（플레이어 관점）

- **직교 인접**하고 양쪽 모두 이동 가능한 말만 교환 가능.
- 돌, 나무, 웅덩이 칸은 교환 대상 불가. 잠긴 코끼리는 교환 불가（사냥감을 옮겨옴）.
- 교환 후 가로·세로에 「합법 3연결」이 없으면 → 되돌림, **스텝 미차감, 시간 미차감**.
- 합법 3연결 있음 → 1스텝 차감（제한 시간 스테이지는 스텝 차감 없음, 시계만 감）.
- 연쇄가 전부 끝나야 다음 클릭 수락; 연쇄 중 보드 클릭 무효.
- 대각 3연결은 인정 안 함. L / T자 교차는 각 칸 한 번만 소거.

## 6. 세 가지 소거（기능）

우선순위: **코끼리 > 생태 > 동종**. 한 줄은 최고 우선순위로만 한 번 점수 계산.

### 6.1 동종

**같은 종** 3개 이상이 한 줄. 예: 사과-사과-사과.

| 길이 | 플레이어가 보는 결과 |
|------|----------------|
| 3 | 축소 소멸, 기본 점수 |
| 4 | 소멸, 중앙 칸에 비료 생성 |
| 5+ | 소멸, 스킬 슬롯 +1 충전（스테이지 허용 스킬 제한 적용） |

### 6.2 생태（포식）

한 줄에 **정확히 상성자 1개**, 나머지는 전부 그 사냥감, 사냥감 동종 불필요. 예: 닭-개미-무당벌레.

| 상성자 | 먹을 수 있음 | 못 먹음 |
|--------|------|--------|
| 닭, 오리, 거위 | 꽃, 채소, 과일, 벌레 | 오곡 |
| 개 | 닭, 오리, 거위, 비둘기 등 가금 | 식물, 벌레 |
| 돼지 | 나무, 꽃, 채소, 과일, 벌레, 오곡 | 개 |
| 소, 말 | 꽃, 오곡, 묘목 | 벌레, 고기 |
| 코끼리 | 6.3 참조 | 장애물, 농기구 |

플레이어가 보는 것: 포식 애니메이션 → 세 칸 전부 비워짐（V1은 상성자도 함께 퇴장）→ 상성자 원래 칸에 비료 잔류.

### 6.3 코끼리

한 줄에 코끼리 1마리 + 다른 두 칸의 임의 소거 가능 말 → 세 칸 클리어, 진영 무시. 판 위 최대 1마리. 일반 교환에서 「합성」되지 않음; 연타 5회 달성 시 시스템이 빈 상단 칸에 드롭하거나, 스테이지 시작 배치.

## 8. 스테이지 사양

승패는 **전체 연쇄 애니메이션 종료 후** 정산.

### 8.1 풍년 스테이지

- 풀: 밀, 쌀, 옥수수, 배추, 토마토, 사과, 닭, 오리; 개미/무당벌레 저가중치.
- 승: 20스텝 내 **plant 역할 50개** 소거（오곡+채소+과일+꽃）. 닭·오리가 소거돼도 미포함.
- 패: 스텝 0이고 목표 미달.
- 스킬: 낫（충전 후 사용 가능）.
- 튜토리얼: ①인접 교환 클릭 ②셋이 같으면 소거 ③닭은 옆 벌레 2마리/채소/과일을 먹지만 밀은 안 먹음.

### 8.2 쫓아내기 스테이지

- 풀: 닭, 오리, 거위, 비둘기, 개. 식물 없음.
- 승: **90초** 안에 **개의 생태 소거**로 가금 15마리 제거.
- 패: 시간 초과.
- **닭 3마리 동종 소거는 목표 미포함**（반드시 개가 가금을 먹는 생태 완성）.
- 스킬: 없음. 일시정지 시 타이머 정지.

### 8.3 파괴왕 스테이지

- 풀: 밀, 사과, 장미, 돼지（저가중치）. 고정 소나무 3그루, HP=5, 교환 불가, 낙하 통과 불가.
- 승: 나무 3그루 HP 0.
- 패: 25스텝 소진.
- 나무 피해: 돼지 생태（나무가 사냥감 run에 있음）-2; 돼지 3마리 한 줄이 **3×3 받아치기** 발동（범위 내 나무 -5）; 괭이 단일 -3; 일반 인접 3소거 -1.
- 스킬: 괭이.

### 8.4 코끼리 축제

- 풀: 밀, 사과, 닭, 개, 돼지. 시작 시 중앙 부근 잠긴 코끼리 1마리.
- 승: **코끼리 규칙**으로 30칸 소거（동종/생태는 이 목표 미포함）.
- 패: 30스텝 소진.
- 두 번째 코끼리 리젠 없음. 플레이어가 사냥감을 코끼리 양옆 또는 위아래로 교환.
- 스킬: 없음.

## 9. 장애물, 비료, 스킬

| 기능 | 플레이어 인지 | 규칙 |
|------|----------|------|
| 돌 | 회색, 클릭 불가 | HP3; 인접 소거마다 -1; 괭이 한 번에 부숨 |
| 나무 | 큰 모델, 클릭 불가 | 파괴왕 참조 |
| 웅덩이 | 칸면 반사 | 위 말이 웅덩이 한 칸 위에 멈춤; 물통으로 물 뺀 후 낙하 재개 |
| 비료 | 칸면에 짙은 무더기 | 그 칸이 다음에 소거되면 점수 ×2, 이후 사라짐 |
| 낫 | 하단 바 아이콘 | 한 줄 또는 한 열 선택, 식물만 소거, 스텝 미소모, 충전 1 소모 |
| 괭이 | 하단 바 아이콘 | 돌 또는 나무 1개 클릭 |
| 물통 | 하단 바 아이콘 | 웅덩이 1칸 클릭 |

충전: 플레이어 조작 한 번으로 일어난 전체 정산에서 생태 소거가 등장하기만 하면 카운트 +1; 3이 되면 슬롯 1개 획득, 상한 2. 동종 5연결도 +1 슬롯（생태 충전과 슬롯 공유）.

V1 풍년은 돌·웅덩이 없음; 파괴왕은 웅덩이 없음. 웅덩이는 도감에 남겨두고 네 스테이지 메인 라인을 막지 않음.

## 10. 점수와 경제

```
동종     10 × 소거 수 × combo × 비료
생태     25 × 소거 수 × combo × 비료
코끼리   40 × 소거 수 × combo
스킬 청소  8 × 소거 수
장애물 파괴 20 × 부순 수
```

combo: 이번 조작의 첫 소거가 1, 연쇄 라운드마다 +1; 플레이어 다음 수동 조작 시 1로 초기화.

**P4 지갑:**

- 스테이지 선택 시작 시 입장료 차감（기본 스테이지당 게임 코인 1）.
- 클리어 시 별 정산: 남은 자원 ≥50% 3성, ≥20% 2성, 아니면 1성; 보상 2 / 3 / 5（설정 가능）.
- 실패 시 입장료 반환 없음.
- 하나도 교환하지 않고 나가면 → 환불.
- 잔액 부족 시 시작 불가.

V1（P0–P3）은 차감 없음, 로컬에서 바로 플레이 가능.

## 12. 경계（반드시 고정）

1. 도감은 커질 수 있지만, **단일 스테이지 리젠 종류 ≤ 8**.

9. 쫓아내기 스테이지 제한 시간 90초, 스텝 사용 안 함.
