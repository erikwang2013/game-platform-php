## 1. Определение продукта

| Пункт | Содержание |
|----|------|
| Название | 田园消消乐 |
| Тип | три-в-ряд 8×8 + экологическая сдержанность |
| Обзор | фиксированный 2.5D-ортогональный макет, без вращения |
| Управление | клик по двум соседним фигурам для обмена (только вверх/вниз/влево/вправо) |
| Платформа | собственная H5, открывается через `launch` из игрового зала |
| Опыт успеха | три-в-ряд осваивается сразу; при первом «курица ест насекомое» ощущается рост правил; у каскадных выпадений есть ритм |

**V1 не делает:** рейтинги в реальном времени в партии, наблюдение за друзьями, прокачку фигур, открытый мир, точные модели GLTF, пользовательские уровни.

## 2. Путь игрока

```
大厅点「开始」
  → 加载页（读 session）
  → 选关（四关列表 + 余额，P4 才显示扣费）
  → 对局
       HUD：目标 / 步数或倒计时 / 分数 / combo / 技能槽
       棋盘：点击选中 → 点相邻交换
       无消：弹回，不扣步
       有消：扣 1 步 → 消除动画 → 下落 → 补子 → 自动连锁
  → 通关 / 失败结算
  → 下一关 / 重试 / 回选关
```

При первом входе в «Урожай» всплывают 3 подсказки, затем исчезают; их можно пропустить, повторно не появляются (localStorage).

---

## 3. Основной цикл

1. Смотри цель (сколько ещё растений / птицы / деревьев / клеток под слоном).
2. Ищи три одинаковых подряд или подводи сдерживающего к двум жертвам.
3. Обмен → удаление → каскад выпадений.
4. Экологическое удаление оставляет на исходной клетке удобрение: следующее удаление этой клетки даёт очки ×2.
5. Сделай 3 расчёта с экологией — слот навыка загорится; серп/мотыга/ведро решают позицию.
6. Цель достигнута и шаги/время ещё есть → победа.

## 4. Интерфейс

| Экран | Элементы | Поведение |
|------|------|------|
| Загрузка | название игры, прогресс | при недействительной session — подсказка вернуться в зал |
| Выбор уровня | карточки четырёх уровней: название, сводка цели, разблокирован ли | в V1 открыты все четыре; в P4 показывается плата за вход |
| Верх HUD партии | название уровня, прогресс-бар цели, оставшиеся шаги или отсчёт, очки, combo | отсчёт идёт по секундам, при паузе замораживается |
| Низ HUD партии | слоты навыков (максимум 2), пауза | незаряженные слоты серые |
| Доска | участки 8×8 + фигуры | выделение — подскок+обводка; нелегальные клетки без обводки |
| Пауза | продолжить / перезапустить / сдаться | перезапуск тратит одну попытку; сдаться — засчитывается поражение |
| Победа | очки, оставшиеся шаги, выплата или нет (P4) | следующий уровень / вернуться к выбору |
| Поражение | причина (шаги/таймаут), нехватка до цели | повторить / вернуться к выбору |
| Недостаточно средств | текст + переход к пополнению | только P4 |

Клавиатура (P5): стрелки меняют выделение, Enter обменивает с фигурой по направлению. В V1 — только мышь/тач.

## 5. Правила операций (с точки зрения игрока)

- Обменивать можно только **ортогонально соседние** фигуры, причём обе должны быть подвижны.
- Камень, дерево, лужа не могут быть объектами обмена. Зафиксированного слона нельзя поменять местами (подводится жертва).
- Если после обмена по горизонтали или вертикали нет «легальной тройки» → возврат, **шаг и время не тратятся**.
- Есть легальная тройка → тратится 1 шаг (в уровнях на время шаг не тратится, идут только часы).
- Следующий клик принимается только после полного проигрывания каскада; во время каскада клики по доске недействительны.
- Диагональные тройки не считаются. L/T-образные пересечения удаляют каждую клетку один раз.

## 6. Три вида удаления (функции)

Приоритет: **слон > экология > один вид**. Одна линия начисляет очки только по высшему приоритету.

### 6.1 Один вид

Три и более **фигуры одного вида** подряд. Пример: яблоко-яблоко-яблоко.

| Длина | Что видит игрок |
|------|----------------|
| 3 | уменьшается и исчезает, базовые очки |
| 4 | исчезает, в центральной клетке появляется удобрение |
| 5+ | исчезает, слот навыка +1 заряд (в пределах разрешённых навыков уровня) |

### 6.2 Экология (охота)

В линии **ровно 1 сдерживающий**, остальные — его добыча; добыча не обязана быть одного вида. Пример: курица-муравей-божья коровка.

| Сдерживающий | Может есть | Не может есть |
|--------|------|--------|
| Курица, утка, гусь | цветы, овощи, фрукты, насекомых | зерновые |
| Собака | кур, уток, гусей, голубей и прочую птицу | растения, насекомых |
| Свинья | деревья, цветы, овощи, фрукты, насекомых, зерновые | собаку |
| Корова, лошадь | цветы, зерновые, саженцы | насекомых, мясо |
| Слон | см. 6.3 | препятствия, инструменты |

Игрок видит: анимация охоты → три клетки пустеют (в V1 сдерживающий уходит вместе с добычей) → на исходной клетке сдерживающего остаётся удобрение.

### 6.3 Слон

Линия из 1 слона + любые две удаляемые фигуры в других клетках → очищаются три клетки, без учёта фракции. На доске максимум 1 слон. Обычным обменом не «собирается»; при серии из 5 выпадает системой на пустую верхнюю клетку или ставится при старте уровня.

## 8. Спецификация уровней

Итог победы/поражения подводится **после завершения всего каскада анимаций**.

### 8.1 Уровень «Урожай»

- Пул: пшеница, рис, кукуруза, капуста, помидор, яблоко, курица, утка; муравей/божья коровка с низким весом.
- Победа: за 20 шагов устранить **50** фигур с ролью plant (зерновые+овощи+фрукты+цветы). Съеденные куры/утки не считаются.
- Поражение: шаги на нуле и цель не выполнена.
- Навыки: серп (доступен после зарядки).
- Обучение: ① кликай по соседним для обмена ② три одинаковых удаляются ③ курица может съесть двух соседних насекомых/овощи/фрукты, но не пшеницу.

### 8.2 Уровень «Выгон»

- Пул: курица, утка, гусь, голубь, собака. Без растений.
- Победа: за **90 секунд** экологией **собаки** убрать 15 птиц.
- Поражение: таймаут.
- **Удаление трёх кур одного вида не идёт в цель** (нужна именно экология «собака ест птицу»).
- Навыки: нет. Пауза замораживает отсчёт.

### 8.3 Уровень «Разрушитель»

- Пул: пшеница, яблоко, роза, свинья (низкий вес). Фиксированные 3 сосны, HP=5, не обмениваются, сквозь них не падают.
- Победа: HP трёх деревьев на нуле.
- Поражение: кончились 25 шагов.
- Урон дереву: свиная экология (дерево в run добычи) -2; три свиньи в линию триггерят **арку 3×3** (дерево в зоне -5); мотыга по одному дереву -3; обычное соседнее удаление трёх -1.
- Навыки: мотыга.

### 8.4 «Слоновий карнавал»

- Пул: пшеница, яблоко, курица, собака, свинья. На старте 1 зафиксированный слон у центра.
- Победа: устранить 30 клеток **правилом слона** (один вид/экология не идут в эту цель).
- Поражение: кончились 30 шагов.
- Второй слон не спавнится. Игрок подводит жертв к слону по сторонам или сверху/снизу.
- Навыки: нет.

## 9. Препятствия, удобрение, навыки

| Функция | Ощущение игрока | Правило |
|------|----------|------|
| Камень | серый, не кликается | HP3; соседнее удаление -1; мотыга разбивает за раз |
| Дерево | высокая модель, не кликается | см. Разрушитель |
| Лужа | бликует на поверхности клетки | фигура сверху останавливается на клетку выше лужи; после осушения ведром падение возобновляется |
| Удобрение | тёмное пятно на поверхности клетки | следующее удаление этой клетки даёт очки ×2, затем исчезает |
| Серп | иконка в нижней панели | выбрать строку или столбец, очищает только растения, без траты шага, расход 1 заряд |
| Мотыга | иконка в нижней панели | клик по 1 камню или дереву |
| Ведро | иконка в нижней панели | клик по 1 клетке с лужей |

Зарядка: если в полном расчёте от одной операции игрока было экологическое удаление — счётчик +1; на 3 даётся 1 слот, максимум 2. Серия из 5 одинаковых также даёт +1 слот (общий слот с экологической зарядкой).

В V1 в «Урожае» нет камней и луж; в «Разрушителе» нет луж. Лужа остаётся в галерее и не блокирует основную линию из четырёх уровней.

## 10. Очки и экономика

```
同种     10 × 消掉数 × combo × 肥料
生态     25 × 消掉数 × combo × 肥料
大象     40 × 消掉数 × combo
技能清格  8 × 消掉数
破障碍   20 × 破碎数
```

combo: первое удаление операции — 1, за каждый дополнительный каскад +1; при следующей ручной операции сбрасывается на 1.

**P4 — кошелёк:**

- Старт уровня списывает плату за вход (по умолчанию 1 игровая валюта за уровень).
- Прохождение начисляет по звёздам: остаток ресурсов ≥50% — три звезды, ≥20% — две, иначе одна; награда 2 / 3 / 5 (настраивается).
- При провале плата за вход не возвращается.
- Выход без единой перестановки → возврат платы.
- Недостаток средств — начать нельзя.

V1 (P0–P3) без списаний, играется локально.

## 12. Границы (обязательно зафиксировать)

1. Галерея может быть большой, **видов в одном уровне ≤ 8**.
2. Инструменты не попадают на доску.
3. Курица не ест зерновые: линия «курица+пшеница+пшеница» — не экология и не один вид, возврат.
4. Собака не ест растения; свинья не роет собаку.
5. На доске одновременно максимум 1 слон.
6. Во время проигрывания каскада ввод отбрасывается.
7. Итог победы/поражения не подводится посреди анимаций.
8. В V1 сдерживающий уходит вместе с добычей.
9. «Выгон» ограничен 90 секундами, без шагов.
10. Лужа не входит в основную линию четырёх уровней.
